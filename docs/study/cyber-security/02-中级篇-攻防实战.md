# ⚔️ 中级篇 · 攻防实战（第 2 年）

> 目标：掌握完整渗透方法论 + 审计强项变现 + 蓝队护网体验，拿下 CISP-PTE。

## 模块 1：渗透测试方法论（PTES 七步）

侦察 → 扫描 → 枚举 → 利用 → 后渗透 → 报告。每步配一个完整靶机串讲：

- VulnHub 靶机串（Kioptrix 系列 → Mr-Robot → Stapler）：从"扫到打"的完整闭环
- 报告写作：漏洞描述/复现步骤/危害评级/修复建议——工程师的表达力优势区

## 模块 2：Burp 进阶与 Web 深水区

- Intruder/Repeater/Comparer 高效组合、插件开发（你有 Java/Python 功底，写 Burp 插件不是事）
- 逻辑漏洞：越权/支付篡改/验证码缺陷——**扫描器扫不到的才是人的价值**
- JWT/SSRF/XXE/Web 缓存欺骗

## 模块 3：内网渗透概念链

信息收集 → 边界突破 → 权限维持 → 横向移动 → 域控：
- Kerberos 协议与委派攻击（概念+靶场复现，如 AD 靶场）
- CS/MSF 框架认知（**仅靶场使用**）

## 模块 4：代码审计（你的王牌）

20 年代码功底直接变现：
- Java Web：Spring/Struts 历史漏洞模式（反序列化、SpEL/OGNL 注入）
- PHP：弱类型、危险函数、上传绕过
- Python：模板注入（SSTI）、pickle 反序列化、Flask 调试模式
- 方法：危险函数定位 → 数据流回溯 → PoC 验证（static analysis 思路迁移）
- 📚 资源：阿里code-audit谱系、《代码审计：企业级Web代码安全架构》

## 模块 5：蓝队与应急响应（护网入场券）

- 应急响应六步：断网取证→排查→加固→溯源（Linux/Windows 排查清单化）
- SIEM 告警研判：Wazuh/奇安信天眼概念、误报判别
- 流量分析：webshell 识别、C2 特征概念

## 模块 6：SRC 实战（合法真刀）

- 平台：补天、漏洞盒子、各厂 SRC；从教育/政府站点信息收集开始
- 提交规范：标题/危害等级/复现步骤/影响面——**报告质量决定通过率**
- 目标：年内 3+ 有效漏洞（低危也算开张）

## 模块 7：CISP-PTE 备考

- 四大场景：Web 渗透/中间件/操作系统/内网——与你的靶场积累高度重合
- 实操考试，工程师手感占优；2027 年内拿下
