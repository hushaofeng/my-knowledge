## 中文社区与合法实战

- **SRC**：补天、漏洞盒子、字节/阿里/腾讯 SRC
- **护网（HVV）**：每年 HW 季蓝队招聘——初级监测岗就是入场券
- **知识**：先知社区、FreeBuf、安全客、微步在线研究

## 认证路线（中国语境）

```
第1年  NISP（入门，学生/转行者友好）
第2年  CISP-PTE（渗透测试工程师，国内攻防认可度最高）
第3年  OSCP（国际手活认证，含金量硬通货）或 CISP-IRE（应急方向）
```

| 认证 | 费用级 | 特点 |
|---|---|---|
| NISP | 低 | CISP 学生版过渡，笔试友好 |
| CISP-PTE | 中 | 实操考试，国内乙方/护网硬门槛 |
| OSCP | 高 | 24h 实操+报告，国际通用，备考周期长 |

## 法律与职业道德

- 只测**授权资产**：靶场、SRC 范围内、护网授权目标
- 红线：《刑法》285 条（非法侵入/获取数据）、286 条（破坏计算机系统）
- 发现真实漏洞：只提交平台，不公开细节、不留后门、不打扰业务
