# 学习路线图：从工程师到攻防从业者

## 你的起手优势（背景定制）

| 已有资产 | 攻防映射 | 策略 |
|---|---|---|
| 20 年 Python/JS 全栈 | 代码审计、安全工具开发 | **跳过编程课**，直接学"攻击者视角读代码" |
| 系统拆解与 Debug 能力 | 渗透测试方法论 | 你最强的迁移资产 |
| AI 协作工作流 | 信息收集/报告自动化 | 用 AI 杠杆放大 2h/周的碎片时间 |
| 教师转型主线 | 费曼式输出 | 每篇笔记写成"能教别人的教程"，知识双倍固化 |

## 三年阶段设计

### 第 1 年 · 筑基（打地基 + 首证）
- **知识**：TCP/IP 与抓包 → Linux → OWASP Top10 → Python 安全脚本 → 操作系统与域概念
- **实践**：DVWA、攻防世界新手区、TryHackMe、PicoCTF
- **里程碑**：NISP（国家注册信息安全专业人员）证书 + 首次 SRC 试水
- **判断点**：年末确认兴趣浓度，决定第 2 年主攻渗透（攻）还是蓝队（防）

### 第 2 年 · 实战（方法论 + 硬证书）
- **知识**：PTES 渗透流程、内网与域渗透概念、代码审计（Java/PHP/Python Web）、应急响应、SIEM 告警研判
- **实践**：VulnHub 靶机、SRC 月更、护网蓝队（HW 季值班研判）
- **里程碑**：**CISP-PTE**（国内渗透测试入场券，护网认可度高）+ 3+ 个有效 SRC 漏洞
- **判断点**：护网体验后选择长线方向

### 第 3 年 · 专精（分化 + 国际认证 + 反哺教学）
- **方向**（三选一深化）：红队 / 漏洞研究 / 蓝队体系
- **里程碑**：OSCP（国际渗透认证）或 CISP 对应高阶 + 护网正式角色
- **特色收官**：「安全+编程」青少年选修课教案——把攻防变成你科技教师履历的差异化作品

## 时间账本

每周 2h × 52 周 × 3 年 ≈ **312 小时**。策略：工作日 4×20min 碎片（读/看）+ 周末 1×60min（动手）。所有产出沉淀到本知识库，学习即创作。

## 学习原则（写在前面防止跑偏）

1. **靶场优先**：所有动手在授权环境，法律红线见 [总览](./index.md)
2. **输出倒逼输入**：每周必须有一个"产出"（笔记/脚本/靶机报告）
3. **进度可视化**：做完打勾，跑 `scripts/进度统计.py` 刷新面板
4. **允许降级**：某周miss了→顺延，不内疚；连续 3 周miss→砍范围保节奏
