# 🧱 初级篇 · 筑基（第 1 年）

> 目标：建立"网络→系统→Web→攻击面"的完整地图，拿下 NISP，CTF 能上手。

## 模块 1：网络协议（工程师速通版）

你不缺编程，缺的是**包级别**的视野：

- TCP/IP 分层、三次握手/四次挥手——用 Wireshark **抓自己的流量**看，别背书
- HTTP/1.1 vs HTTP/2 vs HTTPS：TLS 握手过程、证书链（抓包对比明文/密文）
- DNS 解析全链路、CDN 与子域名的关系（后面子域名枚举的原理基础）
- 代理/VPN/NAT：流量如何被改写——Burp 挂代理后就懂了
- 📚 资源：《图解 TCP/IP》、Wireshark 官方示例抓包文件

## 模块 2：Linux 与命令行

- 文件系统/权限位/SUID、用户与进程、systemd
- bash 管道哲学：grep/awk/sed 组合出迷你分析器
- 安全工具位：nmap、curl、netcat、sqlmap 先会"用"
- 📚 资源：OverTheWire Bandit（游戏化练命令行，强推）

## 模块 3：Web 安全基础（OWASP Top 10）

每类漏洞按「原理 → 手工利用 → DVWA 复现 → 修复视角」四步走：

1. SQL 注入（联合/布尔/时间盲注，手工优于 sqlmap 先行）
2. XSS（反射/存储/DOM）、CSRF
3. 文件上传/文件包含、SSRF
4. 反序列化（概念）、认证与会话缺陷
- 🔧 工具：Burp Suite Community——安全人的手术刀
- 📚 资源：《Web 安全深度剖析》、DVWA、PortSwigger Web Security Academy（免费，质量极高）

## 模块 4：Python 安全编程（你的超车道）

- socket 端口扫描器（50 行）→ requests 目录爆破 → 子域名枚举
- 异步并发（asyncio）把扫描器提速 50 倍
- PoC/EXP 的工程规范：参数化、日志、退出码——工程师写安全代码，降维打击

## 模块 5：操作系统与内网概念

- Windows 域基础概念：域控/Kerberos/组策略（第 2 年内网渗透的地基）
- Linux 提权思路清单（SUID/cron/Capabilities）
- 密码的存储、散列与破解概念（hashcat 认识一下）

## 模块 6：CTF 入门

- 题型地图：Web/Misc/Crypto/Reverse/Pwn——前三是主战场
- 平台：攻防世界（新手区→进阶区）、Bugku、PicoCTF
- 🎯 目标：独立解出 20 道 Web 题 + 10 道 Misc
