# 01 · 红队方向——认知级攻击视角

> 红队的价值不在"会用工具"，而在**模拟真实对手的完整思维**。本章保持认知与防御视角：理解对手怎么想，才能知道蓝队该防什么、你该练什么。

## 🎯 学习目标

1. 说清红队 / 渗透测试 / 漏洞赏金的角色差异
2. 用 Kill Chain 与 ATT&CK 双视角画出攻击生命周期
3. 理解 EDR 的检测原理（"被怎么看见"）
4. 制订 OSCP→CRTO 的认证路线

## 📖 核心知识

### 1.1 角色差异表

| 角色 | 目标 | 交付 | 约束 |
|---|---|---|---|
| 渗透测试 | 找漏洞证明风险 | 漏洞报告 | 范围明确，广泛扫描 |
| 红队 | 模拟 APT 检验**防御体系** | 攻击链复盘+检测缺口 | 隐蔽、低噪音、有交战规则(ROE) |
| 漏洞赏金 | 单点漏洞变现 | 漏洞提交 | 平台 scope |

红队考核的是"防守方能不能发现我"，所以红队的核心产出常是**检测缺口清单**——对转行者的启示：懂攻击+懂蓝队研判=紫队，是护网里最抢手的复合角色。

### 1.2 攻击生命周期（双视角）

```
阶段          红队做什么                蓝队该看见什么
侦察      被动收集(OSINT)              很难看见→攻击面收敛
初始访问  钓鱼/边界漏洞                邮件网关/WAF/IDS 告警
执行驻留  免杀载荷落地                 EDR 进程行为/AMSI
权限维持  计划任务/注册表/票据          持久化位置审计
横向移动  凭据滥用+远程服务            4688/网络登录异常
目标达成  数据外带/权限滥用            DLP/出站流量异常
```

### 1.3 EDR 视角：被怎么看见

EDR 的三板斧（理解它才能理解对抗的成本）：
1. **用户态 Hook**：API 调用被挂钩（如进程注入的 WriteProcessMemory 必经之路）
2. **ETW/内核遥测**：进程/线程/网络/文件全事件流
3. **行为序列检测**：单点不告警的"可疑组合"（如 Word→子进程 cmd→外连）

因此现代对抗是"成本游戏"：绕过 EDR 的每种手法都在消耗红队的工程时间——**蓝队只要提高对手成本就是赢**。这也是为什么红队岗位要求开发能力：工具自研/魔改是核心竞争力（你的代码功底在此变现）。

### 1.4 C2 框架认知（概念）

C2 = 攻击者的"指挥通信层"：心跳（Beacon 回连）→ 指令下发 → 结果回传。认知要点：
- 流量形态：固定间隔心跳/休眠抖动、域前置、DNS/ICMP 隐蔽信道（蓝队检测点见中级篇 08）
- 主流框架：Cobalt Strike（行业事实标准）、Sliver（开源）——**仅在自有靶场授权演练**
- 红队基建思维：域名/载荷分发/重定向器的基础设施即代码

### 1.5 认证与成长路线

| 阶段 | 认证 | 定位 |
|---|---|---|
| 第 3 年主目标 | OSCP | 手活+报告的国际硬通货（24h 实操） |
| 进阶 | CRTO | 红队操作（C2/对抗实操） |
| 可选 | CRTP/CRTL | AD 攻击专项 |

OSCP 备考心法：PWK 课件 → Labs（≥50 台）→ 报告模板先行 → 考试时间盒管理（见第 3 年计划 W117-W128）。

## 🔬 动手实操

自建小型攻击模拟（全部自有环境）：Kali + Windows 10 虚拟机 → 用 open-source C2（如 Sliver）完成一次"钓鱼 exe→回连→指令"演练 → **同时开 Sysmon 记录** → 对照 1.2 表看"蓝队本该在哪里看见你"。

## ⚠️ 常见坑

1. 把红队当"免杀炫技"——价值在攻击链完整与检测缺口
2. C2 对接真实互联网——基础设施失控即违法
3. 跳过蓝队视角——纯进攻思维在护网里反而吃瘪
4. OSCP 盲目报课——先 HTB 打到中上位再进 Labs 性价比更高
5. 忽略交战规则（ROE）——红队第一份文件永远是规则书

## ✅ 自测题

<details>
<summary>1. 红队与渗透测试最本质的区别？</summary>

对象不同：渗透测"系统漏洞"，红队测"防御体系有效性"——红队假设漏洞存在，考核的是防守方能否检测与响应。

</details>

<details>
<summary>2. EDR 行为序列检测的例子？</summary>

Office 进程派生 cmd、cmd 发起外连、写入计划任务——单看每步都常见，组合即高危；规则表达为"进程树+动作"关联。

</details>

<details>
<summary>3. 为什么说"提高对手成本"是防御的胜利？</summary>

攻击者的对抗手法需工程投入（时间/技能/基础设施）；每抬高一分成本，低能力对手被挤出，剩下对手的频率与规模都下降。

</details>

<details>
<summary>4. DNS 隐蔽信道为什么难封？</summary>

DNS 是基础服务不能全禁；攻击把数据编码进子域名查询——只能靠熵值/频率异常检测而非简单封端口。

</details>

<details>
<summary>5. ROE（交战规则）通常包含什么？</summary>

范围（IP/域名/员工）、允许的强度（可否社工真实员工/可否致瘫）、时间窗、紧急联系人、数据处理要求。

</details>
