# 05 · 教学融合项目——把攻防变成讲台

> 这是整个三年计划的**收官差异化作品**：一位懂攻防的中学数学/信息教师。市场稀缺度极高，且和你 2027 年的教师转型主线完美咬合。

## 🎯 学习目标

1. 完成 8 课时「网络安全与编程思维」选修课完整教案
2. 掌握青少年安全教育的红线与教学法
3. 用 Python 开发教学沙盘（复用你的工具能力）
4. 完成试讲-反馈-迭代一轮

## 📖 核心知识

### 5.1 青少年安全教育的红线（先立规矩）

- **只教思维与自护，不教攻击手法**：讲"为什么密码要长"≠教"怎么暴力破解"
- 所有演示用**模拟环境/预设剧本**，绝不用真实系统举例
- 培养目标：识别风险（钓鱼/隐私/社会工程）+ 建立兴趣（密码学/逻辑游戏）
- 每节课都有"带回家"的自护清单

### 5.2 八课时大纲（每课时 45 分钟）

| 课时 | 主题 | 核心活动 | 产出 |
|---|---|---|---|
| L1 | 密码学游戏 I | 凯撒密码破译小组赛 | 自制密码卡 |
| L2 | 密码学游戏 II | 频率分析破译"校长的密信" | 破译报告 |
| L3 | 社会工程学 I | 钓鱼邮件找茬（10 封真实改编） | 识别清单 |
| L4 | 社会工程学 II | 情景剧：冒充班主任的电话 | 角色剧本 |
| L5 | Web 如何工作 | 你的 Python 沙盘：输入怎样变成命令 | 截图任务单 |
| L6 | 密码与账户卫生 | 密码强度实验+密码管理器实操 | 家庭密码方案 |
| L7 | AI 时代的隐私 | 深伪识别工作坊+Prompt 泄露演示 | 自护十条 |
| L8 | 结课 | 家庭数字安全审计任务发布 | 审计报告 |

设计原则：**每课时一个"wow 时刻"+一个"带走技能"**；L5 的沙盘是你和"普通信息老师"的分水岭。

### 5.3 教学沙盘：100 行的"漏洞游乐场"

复用第 1 年的 Python 功底，做一个刻意留洞（且可控）的本地小站：

```python
# sandbox_app.py — 教学专用，仅限课堂本地运行
from flask import Flask, request
app = Flask(__name__)
USERS = {'teacher': '123456', 'student': 'abc123'}

@app.route('/login')
def login():
    u, p = request.args.get('u'), request.args.get('p')
    sql = f"SELECT * FROM users WHERE u='{u}' AND p='{p}'"   # ← 故意：教学漏洞
    return f"执行: {sql}<br>结果: {query(sql)}"               # 可视化 SQL 组装过程

# L5 课堂剧本：学生输入 ' OR '1'='1 → 亲眼看见"输入变成命令"
```

课堂价值：学生**看见**字符串拼接的瞬间，比讲十遍"SQL 注入危险"都有效。进阶版本：XSS 留言板沙盘、密码强度可视化沙盘。

### 5.4 成果叙事（写进教师简历）

```
模板：开发了《网络安全与编程思维》校本选修课（8 课时），原创 3 套 Python 教学沙盘，
覆盖 XX 名学生，学生作品/问卷数据（安全意识提升 XX%）——具备攻防技术背景的信息科技教师。
```

数据意识：开课即采集前后测问卷（10 题安全意识量表）——有数据的课程=可复制的教研成果，直接支撑职称与求职。

## 🔬 动手实操

按 W137-W144 计划执行：大纲→教案→沙盘→试讲（家人/社区）→迭代→开源（GitHub 仓库：教案+沙盘+课件，你的首个教育类开源作品）。

## ⚠️ 常见坑

1. 内容超纲讲攻击细节——红线失守，一票否决
2. 教案只有活动没有评价——没有前测后测，成果无法证明
3. 沙盘直接用真实漏洞环境——用刻意构造的教学沙盘
4. 忽略家长视角——L8 的家庭审计把影响力扩展到家长
5. 作品不做开源沉淀——GitHub 是你的第二简历

## ✅ 自测题

<details>
<summary>1. 为什么"教思维不教手法"？</summary>

未成年人场景下，攻击手法无自护价值且有滥用风险；教育的目标是风险识别与防御素养——红线也保护教师自己。

</details>

<details>
<summary>2. 沙盘相比 PPT 演示的教学优势？</summary>

学生亲手触发漏洞并看见完整因果（输入→拼装→执行），建构主义学习：经验先于概念，动机来自"我刚刚做到了"。

</details>

<details>
<summary>3. 前后测问卷为什么关键？</summary>

把"我教过"变成"我教会了"（可量化证据）——这是校本课程评奖、职称材料、求职面试的硬通货。

</details>

<details>
<summary>4. L7 的深伪识别用什么素材？</summary>

公开的演示性深伪视频+自拍照生成的对比样本（征得同意），教"验证渠道而非肉眼判断"的元技能。

</details>

<details>
<summary>5. 开源教案的长期价值？</summary>

建立"教育+安全"复合身份的公开档案；同行复用带来反馈迭代；也是未来 "AI+教育+安全" 内容创业的种子资产。

</details>
