# 🎯 高级篇 · 专精（第 3 年）

> 目标：方向分化定终身，OSCP 或对等高阶认证，攻防任务从"参与"到"有角色"。

## 方向 A：红队（进攻的艺术）

- 免杀与对抗概念：EDR 如何看世界、加载器思路（**靶场自用环境**）
- C2 框架深入（Sliver/Cobalt Strike 认知级）
- 初始访问组合拳：钓鱼仿真、边界资产 pinpoint
- 对应认证：OSCP → CRTO 路线

## 方向 B：漏洞研究（深度挖掘）

- CVE 复现工程化：建自己的 CVE 复现库（每篇复现=一篇博客）
- Fuzzing 入门：AFL/libFuzzer 对文件解析器做突变
- 1-day 挖掘：补丁 diff 分析（你有 diff 阅读天赋）
- 目标产出：1 个 CVE 编号或 1 篇高质量漏洞分析

## 方向 C：蓝队体系（防守纵深）

- 检测规则工程：Sigma 规则编写、ATT&CK 映射
- 蜜罐与欺骗防御、威胁情报落地
- 对应认证：CISP-IRE → GCFA 路线

## 通用模块：云与 AI 安全（未来五年门票）

- 云安全基础：IAM 错配/对象存储越权/元数据 SSRF（各大厂 CTF 常客）
- AI 安全初探：Prompt 注入、模型供应链——你的 AI 工作流优势区

## 🎓 特色收官：教学融合项目

把你两年的攻防笔记改造成**「网络安全与编程思维」青少年选修课教案**（8 课时）：
- 密码学游戏 → SQL 注入沙盘 → 社会工程学情景剧
- 这是"科技数学教师"简历上独一无二的差异化章节：懂攻防的老师，全国稀缺
