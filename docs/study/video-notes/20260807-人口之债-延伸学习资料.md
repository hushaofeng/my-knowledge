# 人口之债：延伸学习资料

## 📚 推荐书籍

### 人口与计划生育

#### 1. 《大国空巢》
- **作者**：易富贤
- **核心观点**：分析中国人口政策的误区
- **重点章节**：
  - 计划生育的历史背景
  - 人口红利的真相
  - 老龄化危机的紧迫性

#### 2. 《人口转变与经济发展》
- **作者**：蔡昉
- **学术价值**：人口经济学的经典研究
- **关键内容**：
  - 人口转型理论
  - 刘易斯拐点
  - 人口红利消失的影响

### 房地产

#### 3. 《房地产周期》
- **作者**：任泽平
- **实用性强**：系统分析房地产周期规律
- **重点内容**：
  - 房地产周期的四个阶段
  - 人口结构对房价的影响
  - 政策调控的效果评估

#### 4. 《中国房地产发展报告》（年度）
- **出版社**：社会科学文献出版社
- **时效性**：最新数据和趋势分析
- **价值**：权威的行业研究报告

### 养老问题

#### 5. 《中国养老金发展报告》
- **出版社**：经济管理出版社
- **专业性**：权威的养老金研究
- **内容**：
  - 养老金制度分析
  - 城镇职工养老保险
  - 城乡居民养老保险

#### 6. 《养老保障制度研究》
- **作者**：郑功成
- **学术价值**：社会保障领域权威著作
- **重点**：
  - 养老保险制度设计
  - 国际比较
  - 改革路径

## 💡 学习路径建议

### 初级阶段（1-2个月）

1. 阅读通俗读物《大国空巢》
2. 观看纪录片《养老中国》
3. 浏览国家统计局人口数据
4. 学习《人口社会学》MOOC课程

### 中级阶段（3-6个月）

1. 研读《人口转变与经济发展》
2. 阅读《房地产周期》
3. 学习《社会保障学》课程
4. 关注政策文件解读

### 高级阶段（6-12个月）

1. 研读学术论文
2. 分析统计数据
3. 撰写研究报告
4. 参与学术讨论
