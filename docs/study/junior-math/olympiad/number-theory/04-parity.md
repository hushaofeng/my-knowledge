# 第 4 章 奇偶分析

> 奇偶分析是"不可能性证明"的第一武器：当一道题问"能否做到"而答案是否定时，八成可以用奇偶性两行解决。它的门槛极低，威力极大——这是数论中最值得先学的章节。

## 知识点精讲

### 1. 奇偶运算律（完整表，必背）

| 运算 | 结果 | 口诀 |
|------|------|------|
| 奇 ± 奇 | **偶** | 同性相加得偶 |
| 偶 ± 偶 | **偶** | |
| 奇 ± 偶 | **奇** | 异性相加得奇 |
| 奇 × 奇 | **奇** | 有偶则偶 |
| 奇 × 偶 | **偶** | |
| 偶 × 偶 | **偶**（且被 4 整除） | |

三条高频推论：

1. **和的奇偶性只取决于加数中奇数的个数**：奇数个奇数之和为奇，偶数个奇数之和为偶
2. **加减不改变奇偶性**：$a+b$ 与 $a-b$ 同奇偶
3. **$n$ 个整数之和与它们任意添加正负号后的和，奇偶性相同**

### 2. 平方数的奇偶特征

$$\text{偶}^2 \equiv 0 \pmod 4, \qquad \text{奇}^2 = (2k+1)^2 = 4k(k+1) + 1 \equiv 1 \pmod 8$$

即：**偶数平方被 4 整除；奇数平方除以 8 余 1**。反过来用（验余数断奇偶）更常见。

### 3. 不可能性证明的标准句式

> 假设可以做到 → 某个量必须既是奇数又是偶数（或必须满足两个矛盾的性质）→ 矛盾 → 不可能。

找到"那个量"是全部技巧所在：它通常是一次操作改变的总量、总次数或总和。

## 经典例题

### 例 1（经典赛题改编）

7 个杯子杯口全部朝上。每次操作同时翻转其中 6 个杯子，能否经过若干次操作使 7 个杯子全部杯口朝下？

::: details 查看解答

**不能。**

每个杯子从"朝上"变"朝下"需要被翻转**奇数次**。若最终全部朝下，7 个杯子被翻的总次数是 7 个奇数之和——**奇数**。

但每次操作翻 6 个杯子，设操作了 $k$ 次，总翻转次数为 $6k$——**偶数**。

奇数 ≠ 偶数，矛盾。故不可能。□

**方法提炼：** 双向计算同一个总量（总翻转次数）：按"每个杯子要奇数次"算出奇，按"每次 6 个共 k 次"算出偶，矛盾即成。变量替换（7 杯 / 每次 4 枚 / 每次 6 枚）不影响论证结构。
:::

### 例 2（经典赛题改编）

黑板上写着 $1, 2, 3, \dots, 2025$ 这 2025 个数。每次擦去任意两个数 $a, b$，写上 $a + b$（或 $|a - b|$）。问：操作到只剩一个数时，这个数的奇偶性是否确定？

::: details 查看解答

**确定，一定是奇数。** 关键是找到一个**不变量**。

设黑板上所有数之和为 $S$。擦去 $a, b$ 写上 $a+b$：$S$ 变为 $S - a - b + (a+b) = S$，不变。

擦去 $a, b$ 写上 $|a-b|$：$S$ 变为 $S - a - b + |a-b| = S - 2\min(a, b)$，改变量为偶数，**$S$ 的奇偶性不变**。

所以无论怎么操作，最后剩下的一个数 $\equiv$ 初始总和 $\pmod 2$。

初始总和：

$$1 + 2 + \cdots + 2025 = \frac{2025 \times 2026}{2} = 2025 \times 1013$$

奇 × 奇 = **奇**。故最后剩下的数一定是奇数。□

**方法提炼：** 操作类问题第一问永远是"**什么量不变（或只按可预测方式变化）**"。奇偶性是最常见的廉价不变量。
:::

### 例 3（经典赛题改编）

证明：完全平方数除以 4 的余数只能是 0 或 1；除以 8 的余数只能是 0、1 或 4。

::: details 查看解答

**模 4**：偶数 $n = 2k$，$n^2 = 4k^2 \equiv 0 \pmod 4$；奇数 $n = 2k+1$，$n^2 = 4k^2 + 4k + 1 \equiv 1 \pmod 4$。

**模 8**：奇数部分上面已证 $n^2 = 4k(k+1) + 1$，而 $k(k+1)$ 是相邻两数之积必为偶，故 $4k(k+1)$ 被 8 整除，$n^2 \equiv 1 \pmod 8$。偶数 $n = 2k$：$n^2 = 4k^2$，$k$ 偶时 $\equiv 0 \pmod 8$，$k$ 奇时 $k^2 \equiv 1 \pmod 2$，$n^2 \equiv 4 \pmod 8$。□

**方法提炼：** 这是"平方数"家族题的总开关：见到平方数条件，先按模 4 或模 8 的余数筛一遍。
:::

### 例 4（经典赛题改编）

是否存在整数 $a, b$，使得 $a^2 + b^2 = 2023$？

::: details 查看解答

**不存在。** 由例 3，$a^2, b^2 \pmod 4$ 只能取 0 或 1，所以 $a^2 + b^2 \pmod 4 \in \{0, 1, 2\}$。

而 $2023 = 4 \times 505 + 3$，即 $2023 \equiv 3 \pmod 4$，不在集合内。矛盾，故不存在。□

**方法提炼：** "平方和"问题先算目标数 $\bmod 4$：余 3 直接判死刑。这是两行结束战斗的经典结构。
:::

### 例 5（经典赛题改编）

能否把 $1, 2, \dots, 9$ 填入 $3 \times 3$ 方格表，使每一行、每一列的三个数之和都是偶数？

::: details 查看解答

**不能。** 1~9 中有 5 个奇数、4 个偶数。

每行之和为偶 ⟺ 该行奇数的个数为偶数（0 或 2）。于是三行所含奇数总数 = 三个偶数之和 = **偶数**。

但方格表中奇数总数就是 1~9 中奇数的个数 = 5，是**奇数**。矛盾。□

（用"列"看结论一样。本质上：三行总和 = 全表总和，一边必须偶、一边是奇。）

**方法提炼：** 填表问题用"**按行看一遍、整体看一遍**"的双向计数。奇数的个数既是局部的约束又是全局的事实。
:::

### 例 6（希望杯风格）

25 个人参加聚会，每人恰好与其他若干人握手。证明：握手次数为奇数的人必为偶数个。

::: details 查看解答

设握奇数次的有 $x$ 人，握偶数次的有 $y$ 人，$x + y = 25$。

所有握手次数之和 = 每次握手被 2 个人计入 → 总和为偶数。

$$\text{总和} = (\text{奇数} \times x) + (\text{偶数} \times y)$$

总和的奇偶性 = $x$ 的奇偶性（偶数项不影响）。总和为偶 ⟹ $x$ 为偶数。□

**方法提炼：** "握手"类问题的灵魂是**度数和 = 2 × 边数**（偶性）。本题结论是图论中"奇点必偶数个"的初等版本，竞赛里直接当引理用。
:::

## 习题

1. 不用计算，判断 $1 + 2 + 3 + \cdots + 99$ 的奇偶性。
2. 任意写出 3 个整数，证明其中必有两个数之和为偶数。
3. 一次聚会上每人握了若干次手。25 个人每人握手次数都是奇数，可能吗？说明理由。
4. 已知两个整数之和是奇数。证明：它们的平方和也是奇数。
5. 证明：任何完全平方数除以 8 余 0、1 或 4。（例 3 已证，独立重写一遍）
6. 能否将 $1, 2, \dots, 15$ 排成一圈，使任意相邻两数之和都是完全平方数？（提示：先列出行得通的平方数：4, 9, 16, 25；再看 15 的邻居只能是谁）
7. 黑板上写着 1~2025，每次擦去两个数 $a, b$，写上 $|a-b|$。最后剩下的数是奇数还是偶数？请给出理由。
8.（压轴）桌上有 15 枚硬币全部正面朝上，每次操作同时翻转其中 4 枚。能否使所有硬币反面朝上？请证明你的结论。

::: details 习题答案与提示

1. 1~99 中奇数有 50 个（偶数个），和为**偶**。（$4950$，验证一致）
2. 按奇偶分类只有两类，3 个数放进 2 类必有同类的一对，其和为偶。（抽屉原理第一次露面——组合模块第 2 章正式学）
3. 不可能。握手总次数 = 25 个奇数之和 = 奇数，但每次握手贡献 2 次，总和必为偶。
4. $a + b$ 奇 ⟹ $a, b$ 一奇一偶 ⟹ $a^2, b^2$ 一奇一偶 ⟹ 平方和为奇。
5. 见例 3 解答，独立复述：奇 $\to \equiv 1$；偶 $\to 4k^2$，$k$ 奇偶讨论得 $\equiv 0$ 或 $4$。
6. **不能**。相邻和可能的完全平方数只有 4, 9, 16, 25。看数字 8：$8+1=9$，而 $8+17=25$ 超出范围、其他和（$8+8=16$ 需自配）不合法——8 的"合法邻居"**只有 1**。但在圆圈排列中每个数必须有两个邻居，矛盾。
7. **奇数**。与例 2 完全同构：总和奇偶性不变（改变量 $2\min$），初始和 $2025 \times 1013$ 为奇。
8. **不能**。每枚硬币要变面需被翻奇数次，15 枚合计奇数；每次 4 枚共 $4k$ 次合计偶数。奇偶矛盾。
:::

## 本节方法小结

- **运算律先行**：动手前先默写三句话——同性得偶、异性得奇、有偶则偶
- 不可能性证明 = 找一个**双向计算的量**（总翻转次数、总和、度数和）
- 操作类问题先问**不变量**：奇偶性是免费的不变量
- **平方数 $\bmod 4 \in \{0,1\}$**、**奇平方 $\equiv 1 \pmod 8$**：平方和问题的第一刀
- 填表/排圈问题：**局部约束（每行每列）与全局事实（总数）双向对账**
