# 第 6 章 不定方程

> 两个未知数一个方程，解本该有无穷多——但限定**整数解**后，答案可能有限、甚至为零。不定方程是数论前三章（整除、质因数、同余）的汇演舞台：**可解性看 GCD，找解靠同余，数解用枚举**。

## 知识点精讲

### 1. 二元一次不定方程的可解性定理

$$ax + by = c \quad (a, b \neq 0)$$

**有整数解 $\iff \gcd(a, b) \mid c$**

例：$9x + 6y = 38$ 无整数解，因为 $\gcd(9,6) = 3 \nmid 38$——左边永远是 3 的倍数，右边不是。

**这条判定是"先斩后奏"的利器**：复杂应用题先验可解性，无解直接收工。

### 2. 通解结构

若 $(x_0, y_0)$ 是 $ax + by = c$ 的一组特解，则全部整数解为

$$x = x_0 + bt, \qquad y = y_0 - at \qquad (t \text{ 取遍整数})$$

原因：两个解相减满足 $a\Delta x + b\Delta y = 0$，即 $\Delta x = bt', \Delta y = -at'$（用到 $\gcd(a,b) \mid$ 两边后互质）。

### 3. 找特解的标准姿势：同余法

对 $ax + by = c$，把 $x$ 看作未知数：$ax \equiv c \pmod b$，在模 $b$ 下解出 $x$（枚举 $b$ 个余数即可，$b$ 不大时最快）。

### 4. 正整数解的计数

通解中令 $x \ge 1, y \ge 1$，得到 $t$ 的范围，数整数 $t$ 的个数即可。

### 5. 平方型不定方程的降维打击

$x^2 = k$ 型看平方数特征；$x^2 + y^2 = c$ 型先算 $c \bmod 4$；$x^2 - y^2 = c$ 型因式分解 $(x+y)(x-y) = c$——**乘积拆对，奇偶配对**。

## 经典例题

### 例 1（经典赛题改编）

求 $3x + 4y = 22$ 的全部正整数解。

::: details 查看解答

可解性：$\gcd(3,4) = 1 \mid 22$ ✓。

同余法求特解：$3x \equiv 22 \equiv 1 \pmod 4$，枚举 $x = 1, 2, 3$：$3 \times 3 = 9 \equiv 1$ ✓ → 特解 $(3, 4)$？验证 $3 \times 3 + 4 \times 4 = 25 \ne 22$——代入原方程修正：$x=3$ 时 $y = (22-9)/4 = 13/4$ 非整数。重新做：$3x \equiv 22 \pmod 4$，$22 \equiv 2 \pmod 4$，$3x \equiv 2$，枚举 $x=2$：$6 \equiv 2$ ✓。特解 $(2, 4)$：$6 + 16 = 22$ ✓。

通解：$x = 2 + 4t,\ y = 4 - 3t$。

正整数限制：$x \ge 1 \Rightarrow t \ge -\frac{1}{4}$；$y \ge 1 \Rightarrow t \le 1$。所以 $t = 0, 1$：

$$(x, y) = \boxed{(2, 4),\ (6, 1)}$$

**方法提炼：** 同余解特解时**每一步都代回原方程验证**，特解错则通解全错。
:::

### 例 2（经典赛题改编）

求 $7x + 11y = 244$ 的正整数解的组数。

::: details 查看解答

$7x \equiv 244 \pmod{11}$。$244 = 11 \times 22 + 2 \equiv 2$；$7^{-1} \bmod 11 = 8$（$7 \times 8 = 56 \equiv 1$）。

$x \equiv 16 \equiv 5 \pmod{11}$ → $x = 5, 16, 27, \dots$

$x = 5 \Rightarrow y = (244 - 35)/11 = 19$ ✓；$x = 16 \Rightarrow y = (244-176)/11 = 72/11$ ✗ 非整数——重新枚举：改用 $11y \equiv 244 \pmod 7$，$11 \equiv 4$，$244 \equiv 6 \pmod 7$，$4y \equiv 6$，$4^{-1} \equiv 2$（$4 \times 2 = 8 \equiv 1 \bmod 7$），$y \equiv 12 \equiv 5 \pmod 7$ → $y = 5, 12, 19, \dots$

$y = 5 \Rightarrow x = (244-55)/7 = 27$ ✓；$y = 12 \Rightarrow x = (244-132)/7 = 16$ ✓；$y = 19 \Rightarrow x = (244-209)/7 = 5$ ✓；$y = 26 \Rightarrow x = (244-286)/7 < 0$ ✗。

共 $\boxed{3}$ 组：$(27, 5), (16, 12), (5, 19)$。

**方法提炼：** 计数时用"**较大系数的变量做同余**"（模数大 → 余数类少 → 枚举短）；解出通道后逐个验正性。
:::

### 例 3（经典赛题改编·百钱百鸡）

公鸡 5 元一只，母鸡 3 元一只，小鸡 1 元三只。用 100 元恰好买 100 只鸡，每种至少买多少？列出所有购买方案。

::: details 查看解答

设公鸡 $x$ 只、母鸡 $y$ 只、小鸡 $z$ 只：

$$x + y + z = 100, \qquad 5x + 3y + \frac{z}{3} = 100$$

消去 $z$（$z = 100 - x - y$，金额式乘 3）：$15x + 9y + 100 - x - y = 300$，化简

$$14x + 8y = 200 \iff 7x + 4y = 100$$

解同余：$4y \equiv 100 \equiv 2 \pmod 7$，$4^{-1} \equiv 2$，$y \equiv 4 \pmod 7$ → $y = 4, 11, 18, 25$（$y \le 25$ 才保证 $x \ge 0$）。

| $y$ | $x$ | $z = 100 - x - y$ |
|-----|-----|------|
| 4 | 12 | 84 |
| 11 | 8 | 81 |
| 18 | 4 | 78 |
| 25 | 0 | 75 |

若要求"每种都买"，取前三组；允许不买公鸡则还有 $(0, 25, 75)$。□

**方法提炼：** 三元问题 = **消元降成二元**（消掉约束最松的变量）+ 系数约分 + 同余求通道。"至少各一只"这类语义约束最后处理。
:::

### 例 4（经典赛题改编）

求 $x^2 - y^2 = 45$ 的全部正整数解。

::: details 查看解答

因式分解：$(x+y)(x-y) = 45$。两因子同奇偶（和为 $2x$，差为 $2y$），45 是奇数 → 两因子都是奇数。

45 的奇数因子对（大在前）：$(45, 1), (15, 3), (9, 5)$。

| $(x+y, x-y)$ | $(x, y)$ |
|---|---|
| $(45, 1)$ | $(23, 22)$ |
| $(15, 3)$ | $(9, 6)$ |
| $(9, 5)$ | $(7, 2)$ |

共 $\boxed{3}$ 组。□

**方法提炼：** 平方差方程 = 乘积拆对。同奇偶性是筛子（偶数 $c$ 时恰好是"两因子皆偶或一奇一偶全不行"的变体，$c \equiv 2 \pmod 4$ 时无解）。
:::

### 例 5（经典赛题改编）

一个自然数除以 5 余 2，除以 7 余 3。求满足条件的最小自然数，并写出一般形式。

::: details 查看解答

设 $n = 5a + 2 = 7b + 3$，则

$$5a - 7b = 1$$

特解：$a = 3, b = 2$（$15 - 14 = 1$ ✓）。通解 $a = 3 + 7t$，于是

$$n = 5(3 + 7t) + 2 = 17 + 35t$$

最小自然数 $\boxed{17}$（验证：$17 = 3 \times 5 + 2$ ✓，$17 = 2 \times 7 + 3$ ✓），一般形式 $17 + 35t$。

**方法提炼：** 双余数问题转不定方程是同余章例 6 枚举法的"代数版"——方程观点更通用（条件多时枚举会爆炸）。
:::

### 例 6（初中联赛风格）

求方程 $x + y = xy$ 的全部整数解。

::: details 查看解答

**凑因式变形**：

$$xy - x - y = 0 \Rightarrow xy - x - y + 1 = 1 \Rightarrow (x-1)(y-1) = 1$$

整数乘积为 1 只有两种拆法：

- $x - 1 = 1,\ y - 1 = 1 \Rightarrow (x, y) = (2, 2)$
- $x - 1 = -1,\ y - 1 = -1 \Rightarrow (x, y) = (0, 0)$

共 $\boxed{2}$ 组解。□

**方法提炼：** "$xy$ 与 $x+y$ 混居"的方程，往 $(x-1)(y-1)$、$(x+1)(y+1)$ 方向凑"加一减一"——这一招在 $x + y + xy$ 型组合计数中也会重逢。
:::

## 习题

1. 求 $3x + 5y = 31$ 的全部正整数解。
2. 求 $5x + 7y = 142$ 的正整数解的组数。
3. 鸡兔同笼：35 个头、94 只脚。用不定方程解法求鸡兔各几只。
4. 求 $x^2 - y^2 = 2025$ 的正整数解的组数。（提示：2025 的奇因子对数）
5. 学校租大客车（45 座）与小客车（30 座）送 180 名学生，恰好坐满且两种车都要租。有几种租车方案？哪种方案车最少？
6. 求满足 $x + y = xy$ 的全部整数解。（例 6 已给答案，遮住解答独立完成）
7. 求最小的自然数 $n$，使得 $n$ 除以 5 余 2 且除以 7 余 3。（例 5 已给答案，用方程法独立完成）
8.（压轴）证明：方程 $y^2 - 3x^2 = 2$ 没有正整数解。

::: details 习题答案与提示

1. $3x \equiv 31 \equiv 1 \pmod 5$，$3^{-1} \equiv 2$，$x \equiv 2 \pmod 5$ → $x = 2, 7$（$x=12$ 时 $y<0$）→ $(x,y) = \textbf{(7, 2), (2, 5)}$。
2. $7y \equiv 142 \equiv 2 \pmod 5$，$7 \equiv 2$，$2y \equiv 2$，$y \equiv 1 \pmod 5$ → $y = 1, 6, 11, 16$（$21$ 超界）→ $x = 27, 20, 13, 6$，共 **4 组**。
3. 设鸡 $x$ 兔 $y$：$x + y = 35$，$2x + 4y = 94$ → $x + 2y = 47$ → $y = 12$，$x = 23$。鸡 **23** 只、兔 **12** 只。
4. $(x+y)(x-y) = 2025$，因子皆奇。2025 = $3^4 \times 5^2$ 有 $(4+1)(2+1) = 15$ 个因子；$x > y > 0$ 要求两因子不等且 $x - y \ge 1$。因子对（大/小）：$(675,3), (405,5), (225,9), (135,15), (81,25), (75,27)$，加上 $(2025, 1)$——逐对数：因子对总数 $\frac{15-1}{2} = 7$（因子 45 与自身配对给 $y=0$，舍去）。答案 **7 组**。
5. $45x + 30y = 180 \Rightarrow 3x + 2y = 12$。非负解：$(x,y) = (2,3), (4,0), (0,6)$。两种都租 → 仅 $(2, 3)$？$x=2, y=3$；$x=4, y=0$ 违反"都要租"。**1 种方案：2 大 3 小**（若允许只租一种，另两方案总车数 4、6，均多于 5——顺便验证 2+3=5 辆最多座 5×45=225≥180 ✓）。若题目允许"至少一种"，最少车数方案是 $x=4$（4 辆大车）总 4 辆。按"都要租"答案：**唯一方案 2 大 + 3 小**。
6. $(x-1)(y-1) = 1$ → $(2, 2)$ 与 $(0, 0)$。
7. $5a - 7b = 1$，特解 $(3, 2)$，$n = 17 + 35t$ → 最小 **17**。
8. 两边 mod 3：$y^2 \equiv 2 \pmod 3$。但平方数 $\bmod 3 \in \{0, 1\}$（第 5 章习题 4），矛盾。□
:::

## 本节方法小结

- 动笔前先验**可解性**：$\gcd(a,b) \mid c$，不整除直接宣告无解
- 特解用**同余法**求，每步代回验证；通解 $x = x_0 + bt,\ y = y_0 - at$
- 数正整数解 = 对 $t$ 解不等式组数整点
- 平方差型**乘积拆对 + 奇偶筛**；$x+y=xy$ 型凑 $(x\mp1)(y\mp1)$
- 无解证明常是**一行同余**（如平方数 $\bmod 3 \in \{0,1\}$）——先算余数再碰方程
