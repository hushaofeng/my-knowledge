# 第 3 章 约数与倍数

> 最大公约数（GCD）与最小公倍数（LCM）是数论的"瑞士军刀"。本节掌握三件事：**用质因数分解算 GCD/LCM**、**$ab = \gcd \times \operatorname{lcm}$ 恒等式**、**辗转相除法**。

## 知识点精讲

### 1. 由质因数分解求 GCD 与 LCM

对 $a, b$ 写出质因数分解，**公共质数取指数较小者为 GCD，较大者为 LCM**：

$$a = 252 = 2^2 \times 3^2 \times 7, \qquad b = 420 = 2^2 \times 3 \times 5 \times 7$$

$$\gcd = 2^2 \times 3 \times 7 = 84, \qquad \operatorname{lcm} = 2^2 \times 3^2 \times 5 \times 7 = 1260$$

### 2. 核心恒等式（两数时成立）

$$a \cdot b = \gcd(a, b) \times \operatorname{lcm}(a, b)$$

原因：$\gcd$ 收走了公共质数的"低次"，$\operatorname{lcm}$ 收走了"高次"，两者合并恰好是 $a, b$ 中质因数指数的并集之和。**三数以上此式不成立**（常见陷阱）。

**参数化技巧**：若 $\gcd(a,b) = d$，可写 $a = dm,\ b = dn$，其中 $\gcd(m,n)=1$；此时 $\operatorname{lcm}(a,b) = dmn$。

### 3. 辗转相除法（欧几里得算法）

$$\gcd(a, b) = \gcd(b,\ a \bmod b) \qquad (b \neq 0)$$

反复迭代直到余数为 0，最后一个非零余数就是 GCD。

证明核心：若 $c \mid a$ 且 $c \mid b$，则 $c \mid (a - bq) = a \bmod b$；反之亦然——两式的公约数集合完全相同。

**互质的两个常用结论**：

- $\gcd(n, n+1) = 1$（相邻整数互质）
- $\gcd(n, n+2) = 1 \text{ 或 } 2$（$n$ 奇时相邻奇数互质）

### 4. 余数相同 / 余数相关的 LCM 应用

- "$a, b$ 除以 $m$ 余数相同" $\iff m \mid (a - b)$
- "除以 3、4、5 都余 1 的最小数" = $\operatorname{lcm}(3,4,5) + 1$

## 经典例题

### 例 1（经典赛题改编）

用辗转相除法求 $\gcd(420, 252)$。

::: details 查看解答

$$420 = 252 \times 1 + 168$$
$$252 = 168 \times 1 + 84$$
$$168 = 84 \times 2 + 0$$

最后一个非零余数为 $\boxed{84}$。与质因数分解法结果一致（见知识点 1）。

**方法提炼：** 辗转相除不需要分解质因数，大数求 GCD 时比分解快得多——这也是它出现在算法课而不是算术课的原因。
:::

### 例 2（经典赛题改编）

两个自然数的最大公约数是 12，最小公倍数是 720，乘积为 8640。求这两个数。

::: details 查看解答

设 $a = 12m,\ b = 12n$（$\gcd(m,n)=1$）。

由恒等式：$\operatorname{lcm} = 12mn = 720 \Rightarrow mn = 60$。

验证：$ab = 12m \times 12n = 144 \times 60 = 8640$ ✓（与题设一致）。

互质分解 $60 = mn$：$(1, 60), (3, 20), (4, 15), (5, 12)$（$(2,30),(6,10)$ 不互质，舍）。

对应 $(a, b) = (12, 720), (36, 240), (48, 180), (60, 144)$。

**方法提炼：** GCD/LCM 双条件题的标准解法——参数化 $a=dm, b=dn$ → 互质条件收网。
:::

### 例 3（经典赛题改编）

已知两个自然数的最大公约数是 4，最小公倍数是 120。求两数之和的最小值。

::: details 查看解答

设 $a = 4m,\ b = 4n$，$\gcd(m,n)=1$，$\operatorname{lcm} = 4mn = 120 \Rightarrow mn = 30$。

互质分解：$(1,30) \to (4,120)$ 和为 124；$(2,15) \to (8,60)$ 和为 68；$(3,10) \to (12,40)$ 和为 52；$(5,6) \to (20,24)$ 和为 44。

和最小为 $\boxed{44}$（两数 20 与 24）。

**方法提炼：** "两数越接近和越小"——先找 $mn$ 的互质分解中最接近的一对。
:::

### 例 4（经典赛题改编）

三个齿轮两两啮合，齿数分别为 24、36、40。从某齿第一次对齐到第二次对齐，每个齿轮各转了多少圈？

::: details 查看解答

对齐所需"齿数步"为三齿数的最小公倍数：$\operatorname{lcm}(24, 36, 40)$。

$24 = 2^3 \times 3$，$36 = 2^2 \times 3^2$，$40 = 2^3 \times 5$ → $\operatorname{lcm} = 2^3 \times 3^2 \times 5 = 360$。

各轮转数 = $360 \div$ 各自齿数：$\dfrac{360}{24} = 15$ 圈，$\dfrac{360}{36} = 10$ 圈，$\dfrac{360}{40} = 9$ 圈。

**方法提炼：** 周期重合 = LCM；"每个对象转几圈"用 LCM 除以各自周期。注意三数 LCM 不能用 $ab = \gcd \cdot \operatorname{lcm}$（两数版恒等式）。
:::

### 例 5（经典赛题改编）

在 $1 \sim 100$ 中，恰有 9 个约数的自然数有哪些？

::: details 查看解答

$9 = (a_1+1)(a_2+1)\cdots$，分解方式：$9 = 9$ 或 $9 = 3 \times 3$。

- 结构 $p^8$：$2^8 = 256 > 100$，舍
- 结构 $p^2 q^2$：$2^2 \times 3^2 = 36$ ✓；$2^2 \times 5^2 = 100$ ✓；$3^2 \times 5^2 = 225$ 舍

答案：$\boxed{36,\ 100}$。

**方法提炼：** 约数个数定理的"反查表"用法：先把约数个数拆成大于 1 的因子乘积（按降序写），再分配给最小质数。注意结构 $p^8$ 容易漏想。
:::

### 例 6（初中联赛风格）

已知整数 $x, y$ 互质。证明：$2x + 3y$ 与 $9x + 14y$ 互质。

::: details 查看解答

设 $d = \gcd(2x+3y,\ 9x+14y)$，则 $d$ 整除两式的任何整数组合。

**消去 $x$**：$9(2x+3y) - 2(9x+14y) = 18x + 27y - 18x - 28y = -y$，所以 $d \mid y$。

**再消去 $y$**：$14(2x+3y) - 3(9x+14y) = 28x + 42y - 27x - 42y = x$，所以 $d \mid x$。

于是 $d \mid x$ 且 $d \mid y$，而 $\gcd(x,y) = 1$，故 $d = 1$。□

**方法提炼：** 证明两个线性式互质 = 用**整数系数组合**把它们消元成 $x$ 和 $y$ 本身（消 $x$ 用系数 $9, -2$；消 $y$ 用系数 $14, -3$），然后 GCD 的线性组合性质接管一切。系数怎么找：让 $x$（或 $y$）的系数相消，如 $9 \times 2 - 2 \times 9 = 0$。
:::

## 习题

1. 用辗转相除法求 $\gcd(493, 391)$。
2. 两数的最大公约数为 6，最小公倍数为 108。求两数的一切可能值。
3. 一条路上从起点起，每隔 12 米栽一棵梧桐，每隔 15 米栽一棵松树（起点都栽）。第一次"梧桐与松树同位置"出现在离起点多远？
4. 证明：任意两个相邻的奇数互质。
5. 求自然数 $n$，使得 $\gcd(n, 12) = 4$ 且 $\operatorname{lcm}(n, 12) = 24$。
6. 求除以 3、4、5 余数都是 1 的最小自然数；再求这类数的一般形式。
7. 求 1008 与 1260 的最大公约数与最小公倍数。（用质因数分解）
8.（压轴）甲、乙两数之和是 144，最大公约数是 24。求甲、乙两数所有可能的值。

::: details 习题答案与提示

1. $493 = 391 + 102$；$391 = 3 \times 102 + 85$；$102 = 85 + 17$；$85 = 5 \times 17$ → $\gcd = \textbf{17}$。
2. 设 $a=6m, b=6n$，$\gcd(m,n)=1$，$mn = 108/6 = 18$。互质分解 $(1,18), (2,9)$ → $(a,b) = (6,108)$ 或 $(12,54)$。
3. $\operatorname{lcm}(12, 15) = 60$ → 距起点 **60 米**（此后每 60 米重合一次）。
4. 相邻奇数差为 2，设 $d \mid n$ 且 $d \mid n+2$，则 $d \mid 2$；$n$ 为奇数故 $d$ 为奇数，$d=1$。
5. 枚举 4 的倍数：$n=8$：$\gcd(8,12)=4$ ✓，$\operatorname{lcm}=24$ ✓。答案 **8**（也可参数化：$n=4m$，$mn' \dots$ 枚举更快）。
6. $\operatorname{lcm}(3,4,5) = 60$，最小为 **61**；一般形式 $60k + 1$（$k \ge 0$ 整数）。
7. $1008 = 2^4 \times 3^2 \times 7$，$1260 = 2^2 \times 3^2 \times 5 \times 7$。$\gcd = 2^2 \times 3^2 \times 7 = \textbf{252}$；$\operatorname{lcm} = 2^4 \times 3^2 \times 5 \times 7 = \textbf{5040}$。
8. $a = 24m, b = 24n$，$\gcd(m,n)=1$，$m + n = 6$：$(1,5) \to (24,120)$；$(5,1)$ 同对。$(2,4),(3,3)$ 不互质舍。答案 **24 与 120**。
:::

## 本节方法小结

- GCD/LCM 双条件题第一步永远是**参数化 $a = dm, b = dn$（$m, n$ 互质）**
- $ab = \gcd \times \operatorname{lcm}$ 只对两数成立；三数周期问题直接分解质因数求 LCM
- 大数求 GCD 用**辗转相除**，小数字头用质因数分解
- 线性式互质证明 = **整数系数组合消元**到 $x, y$
- "同余数问题"转化为"差的整除性"（$m \mid a-b$）
