# 第 5 章 同余与周期问题

> "问 $2^{2025}$ 的个位数字""问 $3^{100}$ 天后是星期几"——所有这类问题都是同一个模子：**余数会循环，找到周期就赢了**。同余符号 $\equiv$ 是数论的通用语言，本节把它用熟。

## 知识点精讲

### 1. 同余的定义

$a \equiv b \pmod m$（读作"$a$ 与 $b$ 模 $m$ 同余"）定义为

$$m \mid (a - b), \quad \text{即 } a, b \text{ 除以 } m \text{ 余数相同}$$

例：$17 \equiv 5 \pmod 6$，因为 $6 \mid (17-5)$。

### 2. 同余的性质（运算规则）

设 $a \equiv b,\ c \equiv d \pmod m$，则：

| 性质 | 表达式 | 备注 |
|------|--------|------|
| 加减 | $a \pm c \equiv b \pm d \pmod m$ | ✓ |
| 数乘 | $ka \equiv kb \pmod m$ | ✓ |
| 乘法 | $ac \equiv bd \pmod m$ | ✓ |
| 乘方 | $a^n \equiv b^n \pmod m$ | ✓ |
| 除法 | $\dfrac{a}{c} \equiv \dfrac{b}{d}$ | ✗ **没有这条**！除非 $\gcd(c,m)=1$ |

**除法是唯一要小心的**：$6 \equiv 12 \pmod 6$ 但不能"除以 2"得 $3 \equiv 6$。竞赛陷阱常设在这。

**核心心法**：同余世界（模 $m$）里只有 $m$ 个"数"（$0$ 到 $m-1$），任何加、减、乘、乘方都可以**先降到最后余数再算**。

### 3. 余数周期（核心套路）

若 $a^n \pmod m$ 的余数序列出现重复（如 $a^i \equiv a^j$），则序列以 $j - i$ 为周期循环。

**结论先行**（都是"逐个算余数直到重复"的结果）：

| 幂 | 模 10（个位）周期 | 序列 |
|----|------------------|------|
| $2^n$ | 4 | 2, 4, 8, 6 |
| $3^n$ | 4 | 3, 9, 7, 1 |
| $4^n$ | 2 | 4, 6 |
| $5^n$ | 1 | 恒 5 |
| $6^n$ | 1 | 恒 6 |
| $7^n$ | 4 | 7, 9, 3, 1 |
| $8^n$ | 4 | 8, 4, 2, 6 |
| $9^n$ | 2 | 9, 1 |

**使用方法**：指数 $n$ 除以周期，用**余数**定位（余 0 时取周期末项）。

### 4. 星期问题

星期几 = 总天数 $\bmod 7$。所以"求 $a^n$ 天后星期几"就是求 $a^n \bmod 7$。

## 经典例题

### 例 1（经典赛题改编）

求 $2^{2025}$ 的个位数字。

::: details 查看解答

$2^n$ 的个位周期为 4（序列 2, 4, 8, 6）。

$2025 = 4 \times 506 + 1$，余 1 → 取周期第 1 项：个位数字为 $\boxed{2}$。

**方法提炼：** 三步曲——找周期、指数除以周期取余、按余数查表（余 0 取末项）。
:::

### 例 2（经典赛题改编）

今天是星期四，问 $10^{100}$ 天后是星期几？

::: details 查看解答

只需求 $10^{100} \bmod 7$。$10 \equiv 3 \pmod 7$，于是

$$10^{100} \equiv 3^{100} \pmod 7$$

$3^n \bmod 7$：$3, 2, 6, 4, 5, 1$，周期 6。$100 = 6 \times 16 + 4$，取第 4 项 $3^4 = 81 \equiv 4 \pmod 7$。

星期四再过余 4 天 = 星期四 + 4 = $\boxed{\text{星期一}}$。

**方法提炼：** 先把底数降到最小余数（$10 \to 3$）再找周期，数字小一截；"周四 + 余数"别忘了平移。
:::

### 例 3（经典赛题改编）

求 $1! + 2! + 3! + \cdots + 100!$ 的个位数字。

::: details 查看解答

先看阶乘的个位：$1! = 1$，$2! = 2$，$3! = 6$，$4! = 24$（个位 4），$5! = 120$（个位 **0**）。

从 $5!$ 起每个阶乘都含因数 $2 \times 5 = 10$，个位恒为 0——**后面 96 项全部出局**。

个位 $= (1 + 2 + 6 + 4) \bmod 10 = 13 \bmod 10 = \boxed{3}$。

**方法提炼：** 一旦某项开始"带 0 因子"，之后各项一律贡献 0——长序列题先找"从第几项开始失效"。
:::

### 例 4（经典赛题改编）

求 $2026^{2026}$ 除以 7 的余数。

::: details 查看解答

第一步降底数：$2026 = 7 \times 289 + 3$，所以 $2026 \equiv 3 \pmod 7$，问题变为 $3^{2026} \bmod 7$。

$3^n \bmod 7$ 周期 6（序列 3, 2, 6, 4, 5, 1）。$2026 = 6 \times 337 + 4$ → 取第 4 项 $3^4 = 81 \equiv \boxed{4} \pmod 7$。

**方法提炼：** "降底数 + 降指数"两连招是幂的余数题的标准起手。
:::

### 例 5（初中联赛风格）

证明：$2222^{5555} + 5555^{2222}$ 能被 7 整除。

::: details 查看解答

降底数：$2222 = 7 \times 317 + 3 \equiv 3$；$5555 = 7 \times 793 + 4 \equiv 4 \pmod 7$。

问题变为证 $3^{5555} + 4^{2222} \equiv 0 \pmod 7$。

- $3^n \bmod 7$：周期 6，序列 3, 2, 6, 4, 5, 1。$5555 = 6 \times 925 + 5$ → $3^{5555} \equiv 3^5 \equiv 5$
- $4^n \bmod 7$：周期 3，序列 4, 2, 1。$2222 = 3 \times 740 + 2$ → $4^{2222} \equiv 4^2 \equiv 2$

相加：$5 + 2 = 7 \equiv 0 \pmod 7$。□

**方法提炼：** "和被 $m$ 整除"拆成两块余数，各算各的再拼。两个底数、两个周期，表格别算错行。
:::

### 例 6（经典赛题改编）

求满足"除以 5 余 3，且除以 7 余 4"的最小自然数。

::: details 查看解答

**枚举法（余数通道）**：满足"除以 7 余 4"的数是 $4, 11, 18, 25, 32, \dots$（公差 7）。

逐个检验"除以 5 余 3"：$4 \to 4$✗，$11 \to 1$✗，$18 \to 3$ ✓。

最小值为 $\boxed{18}$。一般解为 $18 + 35k$（$35 = \operatorname{lcm}(5,7)$）。

**方法提炼：** 双余数条件 = 一条等差通道 + 逐个检验。通道选**较大模数**的（项数少，检得快）。
:::

## 习题

1. 求 $3^{100}$ 的个位数字。
2. 今天是星期三，$3^{50}$ 天后是星期几？
3. 求 $777^{777}$ 的个位数字。
4. 证明：任何整数的平方除以 3 余 0 或 1。（提示：整数按 $3k, 3k\pm1$ 分类）
5. 求 $1! + 2! + \cdots + 100!$ 除以 12 的余数。（提示：$5! = 120$ 已被 12 整除）
6. 求 $2^{2025} + 3^{2025}$ 的个位数字。
7. 求满足"除以 5 余 3 且除以 7 余 4"的全部三位数的个数。
8.（压轴）证明：对一切正整数 $n$，$2^n$ 与 $2^{n+4}$ 的个位数字相同。

::: details 习题答案与提示

1. 周期 4（3, 9, 7, 1），$100 = 4 \times 25$ 整除 → 余 0 取末项 → 个位 **1**。
2. $3 \equiv 3 \pmod 7$，周期 6：$3, 2, 6, 4, 5, 1$。$50 = 6 \times 8 + 2$ → $3^2 = 9 \equiv 2$ → 周三 + 2 = **星期五**。
3. $7^n$ 个位周期 4（7, 9, 3, 1），$777 = 4 \times 194 + 1$ → 个位 **7**。
4. $3k$ 平方 $\equiv 0$；$(3k\pm1)^2 = 9k^2 \pm 6k + 1 \equiv 1 \pmod 3$。
5. $1!+2!+3!+4! = 33$，$33 \bmod 12 = \textbf{9}$；$5!$ 起各项含 $3 \times 4 = 12$ 的因子，余 0。
6. $2^{2025}$：$2025 \equiv 1 \pmod 4$ → 个位 2；$3^{2025}$ 同理 → 个位 3。和的个位 **5**。
7. 通道 $18 + 35k \le 999$：$k = 0, 1, \dots, 28$，共 **29 个**（$18, 53, 88, \dots, 998$）。
8. 只需证 $2^{n+4} - 2^n = 2^n \times 15$ 的个位……直接验证更本质：$2^{n+4} = 2^n \times 16 \equiv 2^n \times 6 \pmod{10}$。设 $2^n$ 个位为 $e$（$e \in \{2,4,8,6\}$ 全是偶数），则 $6e \equiv e \pmod{10} \iff 5e \equiv 0 \pmod{10}$，而 $e$ 为偶数时 $5e$ 是 10 的倍数，成立。故个位不变。□
:::

## 本节方法小结

- 幂的余数题三板斧：**降底数 → 找周期 → 指数除周期取余**（余 0 取末项）
- 个位周期表（2,3,4,7,8 周期 4；4,9 周期 2；5,6 周期 1）要形成条件反射
- 阶乘/连乘求尾数：**从哪一项开始带 0 因子**，之后全清零
- 同余可以做加减乘与乘方，**唯独除法要检查互质**
- 双余数找数：小模数当筛子，**大模数的等差通道**当搜索空间
