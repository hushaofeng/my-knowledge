# 第 5 章 不等式与最值

> 最值问题的两大支柱：**均值不等式**（结构好时秒杀）与**二次函数区间最值**（对称轴动起来就分类讨论）。本章的另一主题是含参讨论——竞赛与中考压轴的公共分水岭。

## 知识点精讲

### 1. 不等式的基本性质（三条核心）

| 性质 | 内容 |
|------|------|
| 传递 | $a > b,\ b > c \Rightarrow a > c$ |
| 加法保序 | $a > b \Rightarrow a + c > b + c$（任意 $c$） |
| 乘法分叉 | $a > b,\ c > 0 \Rightarrow ac > bc$；**$a > b,\ c < 0 \Rightarrow ac < bc$（变号！）** |

**含参不等式的铁律**：参数当除数/乘数时必须**分"正、负、零"三种情况**——$ax > 5$ 在 $a < 0$ 时解是 $x < \frac5a$（变号），$a = 0$ 时退化为 $0 > 5$ 无解。

### 2. 均值不等式（$a, b > 0$）

$$a + b \ge 2\sqrt{ab} \qquad \text{（取等：} a = b\text{）}$$

两个使用方向：

- **积定和最小**：$ab$ 固定 → $a + b$ 有下界 $2\sqrt{ab}$
- **和定积最大**：$a + b$ 固定 → $ab \le \left(\dfrac{a+b}{2}\right)^2$

**使用前提三查**：正（$a,b>0$）、二（代数和形式）、等（取等号能否取到）。取不到等号时答案要用单调性另求——这是均值不等式最大的坑。

### 3. 二次函数区间最值（含参三分讨论）

$f(x) = x^2 - 2ax + 3$（开口向上，对称轴 $x = a$）在区间 $[m, n]$ 上的最小值：

| 对称轴位置 | 最小值点 | 最小值 |
|-----------|---------|--------|
| $a < m$（轴在左） | 区间左端 | $f(m)$ |
| $m \le a \le n$（轴在区间内） | 顶点 | $f(a)$ |
| $a > n$（轴在右） | 区间右端 | $f(n)$ |

口诀：**轴定区间定，看轴在哪边；轴动区间定，三分讨论**。

### 4. "1 的代换"（条件 $x + y = \text{定值}$ 的高级用法）

见例 6。

## 经典例题

### 例 1（经典赛题改编）

解关于 $x$ 的不等式：$ax > 5$。

::: details 查看解答

按 $a$ 的符号三分：

- $a > 0$：$x > \dfrac5a$
- $a < 0$：**变号**，$x < \dfrac5a$
- $a = 0$：左边 $= 0$，不等式为 $0 > 5$，**无解**

**方法提炼：** 参数在系数位置 → 第一步永远是"问参数能不能为零、能不能变号"。三个分支一个都不能漏。
:::

### 例 2（经典赛题改编）

已知 $x > 0$，求 $x + \dfrac{4}{x}$ 的最小值；再求 $x < 0$ 时的最大值。

::: details 查看解答

**$x > 0$**：均值不等式

$$x + \frac4x \ge 2\sqrt{x \cdot \frac4x} = 4$$

取等：$x = \frac4x \Rightarrow x = 2 > 0$ ✓。最小值 $\boxed{4}$。

**$x < 0$**：两项一负一负——均值不等式**不能直接用**（前提是正数）！设 $t = -x > 0$：

$$x + \frac4x = -\left(t + \frac4t\right) \ge -4 \text{ 的对偶：} t + \frac4t \ge 4 \Rightarrow x + \frac4x \le -4$$

最大值为 $-4$（$x = -2$ 时取得）。

**方法提炼：** 均值不等式**只对正数生效**；负数场景先"提负号"转化，最值关系同步翻转（最小值变最大值）。
:::

### 例 3（经典赛题改编）

用一根 36 m 的篱笆围一个矩形菜园，求最大面积。

::: details 查看解答

设边长 $x, y$，$2(x+y) = 36 \Rightarrow x + y = 18$（**和定**）。

$$xy \le \left(\frac{x+y}{2}\right)^2 = 81$$

取等：$x = y = 9$。最大面积 $\boxed{81\ \text{m}^2}$（正方形）。

**方法提炼：** 和定积最大——几何版的均值不等式；顺带记住结论"**周长定，正方形最大**"。
:::

### 例 4（经典赛题改编）

已知 $x > 0$，求 $\dfrac{x^2 + 3}{x}$ 的最小值。

::: details 查看解答

先拆分：$\dfrac{x^2+3}{x} = x + \dfrac3x \ge 2\sqrt{3} = 2\sqrt3$。

取等：$x = \sqrt3 > 0$ ✓。最小值 $\boxed{2\sqrt3}$。

**方法提炼：** "分式假高次"先**分离**成 $x + \frac3x$ 的标准形态再上均值。看到 $\frac{x^2 + c}{x}$，条件反射拆两项。
:::

### 例 5（经典赛题改编·含参区间最值）

求 $f(x) = x^2 - 2ax + 3$ 在 $[0, 2]$ 上的最小值（用 $a$ 表示）。

::: details 查看解答

对称轴 $x = a$，开口向上，三分讨论：

- **$a < 0$**（轴在区间左侧）：$f$ 在 $[0,2]$ 递增，最小值 $f(0) = \boxed{3}$
- **$0 \le a \le 2$**（轴在区间内）：最小值 $f(a) = a^2 - 2a^2 + 3 = \boxed{3 - a^2}$
- **$a > 2$**（轴在区间右侧）：$f$ 在 $[0,2]$ 递减，最小值 $f(2) = 4 - 4a + 3 = \boxed{7 - 4a}$

**方法提炼：** 轴动区间定 = **三分讨论**（左/内/右）；每段写清"为什么递增/递减"，答案分段表达。
:::

### 例 6（初中联赛风格）

已知 $x, y > 0$ 且 $x + y = 1$，求 $\left(1 + \dfrac1x\right)\left(1 + \dfrac1y\right)$ 的最小值。

::: details 查看解答

**展开 + "1 的代换"**：

$$\left(1+\frac1x\right)\left(1+\frac1y\right) = 1 + \frac1x + \frac1y + \frac{1}{xy} = 1 + \frac{x+y}{xy} + \frac{1}{xy} = 1 + \frac{2}{xy}$$

（$\frac1x + \frac1y = \frac{x+y}{xy} = \frac{1}{xy}$，其中用了 $x + y = 1$——这就是"1 的代换"。）

由 $x + y = 1$：$xy \le \left(\frac12\right)^2 = \frac14$，且 $xy > 0$，所以 $\frac{2}{xy} \ge 8$。

原式 $\ge 1 + 8 = \boxed{9}$，当 $x = y = \frac12$ 时取等。

**方法提炼：** 条件"$x+y=1$"的价值在**代入制造 $\frac{1}{xy}$**：见到"和为定值 + 分式连乘"，先展开、再代 1、最后均值三连。
:::

## 习题

1. 解不等式：$-2x > 6$。
2. 解关于 $x$ 的不等式：$ax - 1 > x + 3$（按 $(a-1)$ 的符号讨论）。
3. 已知 $x > 0$，求 $2x + \dfrac{8}{x}$ 的最小值。
4. 矩形面积为 64（定值），求周长的最小值。
5. 求 $f(x) = -x^2 + 4x$ 在 $[0, 3]$ 上的最大值与最小值。
6. 求 $f(x) = x^2 - 4ax + 5$ 在 $[0, 2]$ 上的最小值（用 $a$ 表示，$a$ 为实参数）。
7. 已知 $x, y > 0$ 且 $x + y = 4$，求 $\dfrac1x + \dfrac1y$ 的最小值。
8.（压轴）证明：对任意正数 $a, b$，$\left(a + \dfrac1a\right)\left(b + \dfrac1b\right) \ge 4$。

::: details 习题答案与提示

1. 两边除以 $-2$ **变号**：$x < -3$。
2. $(a-1)x > 4$：$a > 1$ 时 $x > \frac{4}{a-1}$；$a < 1$ 时 $x < \frac{4}{a-1}$；$a = 1$ 时 $0 > 4$ 无解。
3. $2x + \frac8x \ge 2\sqrt{2x \cdot \frac8x} = 2\sqrt{16} = \boxed{8}$，取等 $2x = \frac8x \Rightarrow x = 2$。
4. 积定和最小：$x + y \ge 2\sqrt{64} = 16$，周长 $\ge 32$，正方形 $8 \times 8$。答案 **32**。
5. 开口向下，对称轴 $x = 2 \in [0,3]$：最大值 $f(2) = \boxed{4}$；最小值在离轴较远的端点 $x = 0$：$f(0) = \boxed{0}$（$f(3) = 3$ 更大）。
6. 轴 $x = 2a$ 三分：$2a < 0$ 即 $a < 0$ → 最小值 $f(0) = \boxed{5}$；$0 \le 2a \le 2$ 即 $0 \le a \le 1$ → $f(2a) = 4a^2 - 8a^2 + 5 = \boxed{5 - 4a^2}$；$2a > 2$ 即 $a > 1$ → $f(2) = 4 - 8a + 5 = \boxed{9 - 8a}$。
7. $\frac1x + \frac1y = \frac{x+y}{xy} = \frac{4}{xy}$；$xy \le 4$ → $\frac{4}{xy} \ge 1$。最小值 $\boxed{1}$（$x = y = 2$）。
8. 展开：$\left(a+\frac1a\right)\left(b+\frac1b\right) = ab + \frac1{ab} + \frac ab + \frac ba$。前两项：$ab + \frac{1}{ab} \ge 2$（$ab > 0$）；后两项：$\frac ab + \frac ba \ge 2$。相加 $\ge 4$，取等 $a = b = 1$。□
:::

## 本节方法小结

- 含参不等式**三分**（正/负/零）是纪律不是技巧
- 均值不等式三查：**正、二、等**；负数先提负号，取等取不到改走单调性
- 和定积最大、积定和最小——矩形周长/面积双版本都要秒答
- 分式先**分离**（$\frac{x^2+c}{x} \to x + \frac cx$）
- 轴动区间定 → **三分讨论**；开口向下先翻成向上再想
- "$x+y=1$"代换：展开后**把 1 换成 $x+y$** 制造 $\frac{1}{xy}$
