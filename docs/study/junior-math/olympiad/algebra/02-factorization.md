# 第 2 章 因式分解与恒等变形

> 因式分解是代数变形的基本功——竞赛里"卡住的地方十有八九是没看出来该分解"。本章在课内五大方法之上，补上三件竞赛武器：**添拆项**、**待定系数法**、**降次求值**。

## 知识点精讲

### 1. 基本方法清单（复习 + 进阶）

| 方法 | 适用信号 | 示例 |
|------|---------|------|
| 提公因式 | 各项有公共因子 | $x^3 - 3x^2 = x^2(x-3)$ |
| 公式法 | 平方差 / 完全平方 | $x^2 - 9 = (x+3)(x-3)$ |
| 十字相乘 | $x^2 + (p+q)x + pq$ 型 | $x^2 + 7x + 12 = (x+3)(x+4)$ |
| 一般十字 | $ax^2 + bx + c$ | $2x^2 + 5x - 3 = (2x-1)(x+3)$ |
| 分组分解 | 四项 / 六项可两两配 | $ab + ac + b + c = (a+1)(b+c)$ |

### 2. 十字相乘的本质

$x^2 + (p+q)x + pq = (x+p)(x+q)$：**拆中间项系数 = 拆常数项的两个数之和**。

对一般 $ax^2 + bx + c$：竖拆 $a$ 与 $c$，交叉相乘之和凑 $b$：

$$2x^2 + 5x - 3:\quad \begin{matrix} 2x & & -1 \\ & \times & \\ x & & 3 \end{matrix} \quad \to \quad (2x - 1)(x + 3)$$

交叉验证：$2x \cdot 3 + (-1) \cdot x = 5x$ ✓。

### 3. 添拆项法（竞赛核心技巧）

当多项式"看不出来"时，**主动加一项减一项**制造分组机会。方向来自猜想：先用因式定理试探一个根（整数根只能是常数项的约数），猜到根 $a$ 后，让 $x - a$ 显形。

**因式定理**：$f(a) = 0 \iff (x - a)$ 是 $f(x)$ 的因式。

### 4. 待定系数法

已知分解的"形状"（如双十字：两个一次式乘积），设出带未知系数的分解式，展开**比对系数**解方程组。适合双元二次、三元对称式。

### 5. 降次求值（条件求值的暗门）

已知 $x^2 + x - 1 = 0$ 求 $x^3 + 2x^2 + 3$ 之类：不要解出 $x$！**用条件把高次幂逐级降到一次**（$x^2 = 1 - x$，$x^3 = x \cdot x^2 = \cdots$），代入后高次自动坍缩。

## 经典例题

### 例 1（经典赛题改编）

分解因式：$x^2 - 7x + 12$ 与 $2x^2 + 5x - 3$。

::: details 查看解答

第一题：找两数积 12、和 $-7$：$(-3)(-4)$ → $x^2 - 7x + 12 = \boxed{(x-3)(x-4)}$。

第二题：竖拆 $2x, x$ 与 $-1, 3$，交叉 $2x \cdot 3 + (-1) \cdot x = 5x$ ✓ → $2x^2 + 5x - 3 = \boxed{(2x-1)(x+3)}$。

**方法提炼：** 十字相乘口算速度决定解题速度——积与和的拆数要练到 3 秒内。
:::

### 例 2（经典赛题改编）

分解因式：$x^3 + x^2 - 4x - 4$。

::: details 查看解答

四项两两分组（前二提 $x^2$，后二提 $-4$）：

$$x^2(x + 1) - 4(x + 1) = (x+1)(x^2 - 4) = \boxed{(x+1)(x+2)(x-2)}$$

**方法提炼：** 四项式先试"前二后二"；分组后必然出现公因式才对，否则换配对方式（一二三四 ↔ 一三二四）。
:::

### 例 3（经典赛题改编）

分解因式：$x^3 - 3x^2 + 4$。

::: details 查看解答

试探根：常数项 4 的约数 $\pm1, \pm2, \pm4$。$x = 2$：$8 - 12 + 4 = 0$ ✓ → $(x-2)$ 是因式。

**拆项让 $x-2$ 显形**：

$$x^3 - 3x^2 + 4 = x^3 - 3x^2 + 2x + 4 - 2x = x(x^2 - 3x + 2) - 2(x - 2) = x(x-1)(x-2) - 2(x-2)$$

$$= (x-2)\big[x(x-1) - 2\big] = (x-2)(x^2 - x - 2) = \boxed{(x-2)^2 (x+1)}$$

验证：$(x-2)^2(x+1) = (x^2-4x+4)(x+1) = x^3 - 3x^2 + 0x + 4$ ✓。

**方法提炼：** 因式定理先"探路"（知道必有 $x-2$），添拆项只是把 $(x-2)$ **机械地造出来**；两次分解到 irreducible 才算完。
:::

### 例 4（经典赛题改编）

分解因式：$x^2 + 2xy - 8y^2 + 2x + 14y - 3$。

::: details 查看解答

**双十字相乘**。先只看二次部分：$x^2 + 2xy - 8y^2 = (x - 2y)(x + 4y)$。

设原式 $= (x - 2y + m)(x + 4y + n)$。展开比对一次项与常数：

$$x^2 + 2xy - 8y^2 + (m+n)x + (4m - 2n)y + mn$$

比对：

$$\begin{cases} m + n = 2 \\ 4m - 2n = 14 \\ mn = -3 \end{cases}$$

由前两式：$m = 3, n = -1$（验证 $mn = -3$ ✓）。

$$\boxed{x^2 + 2xy - 8y^2 + 2x + 14y - 3 = (x - 2y + 3)(x + 4y - 1)}$$

**方法提炼：** 分解的形状 = 二次部分先分解 + 两个待定常数；三组方程解出后**必须验第三条**（相容性不保证）。
:::

### 例 5（经典赛题改编）

已知 $a + b + c = 0$。证明：$a^3 + b^3 + c^3 = 3abc$。

::: details 查看解答

由**立方和恒等式**：

$$a^3 + b^3 + c^3 - 3abc = (a + b + c)\,(a^2 + b^2 + c^2 - ab - bc - ca)$$

（该恒等式可用待定系数法验证：右式乘开即左式，是本节必背公式。）

条件 $a + b + c = 0$ 使右式第一个因子为 0，于是

$$a^3 + b^3 + c^3 - 3abc = 0 \Rightarrow a^3 + b^3 + c^3 = \boxed{3abc} \qquad \blacksquare$$

**方法提炼：** 对称条件 + 对称多项式 → 背熟的对称恒等式直接接管。$a+b+c=0$ 时 $a^3+b^3+c^3=3abc$ 是竞赛高频结论。
:::

### 例 6（经典赛题改编）

已知 $x^2 + x - 1 = 0$，求 $x^3 + 2x^2 + 2026$ 的值。

::: details 查看解答

**降次**：由条件 $x^2 = 1 - x$。

$$x^3 = x \cdot x^2 = x(1 - x) = x - x^2 = x - (1 - x) = 2x - 1$$

代入：

$$x^3 + 2x^2 + 2026 = (2x - 1) + 2(1 - x) + 2026 = 2x - 1 + 2 - 2x + 2026 = \boxed{2027}$$

**方法提炼：** 条件是二次、目标是三次以上 → **逐级降次**，高次坍缩成一次式后 $x$ 自相抵消——答案与 $x$ 无关不是巧合，是出题结构。
:::

## 习题

1. 分解因式：$4x^2 - 25$。
2. 分解因式：$x^2 + 3x - 10$。
3. 分解因式：$3x^2 - 10x + 8$。
4. 分解因式：$x^3 - 2x^2 - 15x$。
5. 分解因式：$a^4 - 16$（分解到实数范围内不能再分）。
6. 分解因式：$x^3 + x^2 + x + 1$。
7. 已知 $x^2 - x - 1 = 0$，求 $x^3 - 2x + 5$ 的值。
8.（压轴）（1）验证恒等式 $a^3 + b^3 + c^3 - 3abc = (a+b+c)(a^2+b^2+c^2 - ab - bc - ca)$；（2）利用它证明：$a^2 + b^2 + c^2 = ab + bc + ca \iff a = b = c$（实数）。

::: details 习题答案与提示

1. $(2x - 5)(2x + 5)$。
2. $(-2)(-5)$ → $(x - 2)(x + 5)$。
3. 竖拆 $3x, x$ 与 $-4, -2$：交叉 $3x(-2) + x(-4) = -10x$ ✓ → $(3x - 4)(x - 2)$。
4. 先提 $x$：$x(x^2 - 2x - 15) = x(x - 5)(x + 3)$。
5. $a^4 - 16 = (a^2 + 4)(a^2 - 4) = (a^2 + 4)(a + 2)(a - 2)$（$a^2+4$ 实数范围内不可再分）。
6. $(x^3 + x^2) + (x + 1) = x^2(x+1) + (x+1) = (x+1)(x^2 + 1)$。
7. $x^2 = x + 1 \Rightarrow x^3 = x(x+1) = x^2 + x = (x+1) + x = 2x + 1$ → $x^3 - 2x + 5 = (2x+1) - 2x + 5 = \boxed{6}$。
8. (1) 右式按 $a^2, b^2, c^2$ 三块分别乘开合并，交叉项 $-abc$ 出现三次相消后恰得左式；(2) 关键是**配方恒等式** $a^2+b^2+c^2-ab-bc-ca = \frac12[(a-b)^2+(b-c)^2+(c-a)^2]$。必要性：条件成立 ⟺ 该式为 0 ⟺ 三个非负平方项全为 0 ⟺ $a=b=c$。充分性：$a=b=c$ 时显然。
:::

## 本节方法小结

- 十字相乘是**条件反射**；四项式先试前二后二分组
- 分解不出来 → **因式定理试探整数根**（常数项约数），再用添拆项造因式
- 双元二次 → 二次部分先拆 + **待定系数**；解出后验相容
- 条件求值：**降次**，不解方程；答案常与未知数无关
- 必背两条对称恒等式：$a^3+b^3+c^3-3abc$ 分解式与 $\frac12[(a-b)^2+(b-c)^2+(c-a)^2]$
