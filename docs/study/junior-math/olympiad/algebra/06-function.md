# 第 6 章 函数综合

> 函数是初中代数的收官战场。竞赛视角下，二次函数的三大高频考点是：**抛物线族的定点问题**、**与 $x$ 轴交点的弦长**、**顶点的轨迹**——三者的钥匙都是把函数"按参数整理"。

## 知识点精讲

### 1. 三种函数速查

| 函数 | 图象 | 关键性质 |
|------|------|---------|
| $y = kx + b$ | 直线 | $k$ 定方向，$b$ 定截距 |
| $y = \dfrac{k}{x}$ | 双曲线 | $k > 0$ 一三象限；$k < 0$ 二四象限 |
| $y = ax^2 + bx + c$ | 抛物线 | $a$ 开口；$x = -\frac{b}{2a}$ 对称轴；$\Delta$ 定与 $x$ 轴交点 |

### 2. 二次函数的三种表达式（按已知条件选）

| 已知条件 | 选用的形式 |
|---------|-----------|
| 三点坐标 | 一般式 $y = ax^2+bx+c$ |
| 顶点（或对称轴+最值） | 顶点式 $y = a(x-h)^2 + k$ |
| 与 $x$ 轴两交点 | 交点式 $y = a(x-x_1)(x-x_2)$ |

### 3. 弦长公式（与 $x$ 轴交点距离）

$x^2$ 系数为 1 时，若 $\Delta > 0$：

$$|x_1 - x_2| = \frac{\sqrt{\Delta}}{|a|}$$

推导：$(x_1-x_2)^2 = (x_1+x_2)^2 - 4x_1x_2 = \frac{b^2-4ac}{a^2} = \frac{\Delta}{a^2}$。

**应用**：$y = x^2 - 2(m-1)x + m^2 - 2m$ 中 $\Delta = 4$ 恒定 ⟹ 无论 $m$ 如何，弦长恒为 2。这类"不变量"是压轴题最爱。

### 4. 含参函数的两个万能视角

- **过定点**：把函数按**参数**整理（而不是按 $x$），令参数系数为零
- **顶点轨迹**：顶点坐标 $(x_0(m), y_0(m))$ 是参数的函数 → 消参求轨迹

## 经典例题

### 例 1（经典赛题改编）

已知抛物线经过 $(0, 3)$、$(1, 0)$、$(3, 0)$ 三点，求解析式。

::: details 查看解答

与 $x$ 轴交于 $(1,0), (3,0)$ → **交点式**：

$$y = a(x-1)(x-3)$$

代 $(0, 3)$：$a \cdot (-1)(-3) = 3 \Rightarrow a = 1$。

$$\boxed{y = x^2 - 4x + 3}$$

**方法提炼：** 先看给的三点里有没有"零点"——有零点直接交点式，比解三元方程组快一个量级。
:::

### 例 2（经典赛题改编）

求抛物线 $y = x^2 - 2x - 3$ 与 $x$ 轴两交点 $A, B$ 及顶点 $C$ 围成的三角形面积。

::: details 查看解答

令 $y = 0$：$(x-3)(x+1) = 0 \Rightarrow A(-1, 0),\ B(3, 0)$，$|AB| = 4$。

顶点：$x = 1$，$y = 1 - 2 - 3 = -4$ → $C(1, -4)$，高 $= 4$。

$$S_{\triangle ABC} = \frac{1}{2} \times 4 \times 4 = \boxed{8}$$

**方法提炼：** "抛物线 + 三角形面积"三板斧：交点（弦长）→ 顶点（高）→ 底×高÷2。
:::

### 例 3（经典赛题改编）

用图象法解不等式：$x^2 - 2x - 3 > 0$。

::: details 查看解答

$y = x^2 - 2x - 3 = (x-3)(x+1)$，开口向上，与 $x$ 轴交于 $-1, 3$。

"$y > 0$" = 抛物线在 $x$ 轴**上方**的部分 → 两根之外：

$$\boxed{x < -1 \text{ 或 } x > 3}$$

**方法提炼：** 二次不等式 = 看图：开口向上取"两根之外"，开口向下取"两根之间"。口诀"大于看两边，小于看中间"（开口向上时）。
:::

### 例 4（经典赛题改编）

证明：无论 $a$ 取何非零实数，抛物线 $y = ax^2 + 2ax - 3a + 1$ 恒经过两个定点，并求出这两个定点。

::: details 查看解答

**按参数整理**（把 $a$ 当主元）：

$$y = a(x^2 + 2x - 3) + 1$$

要 $y$ 与 $a$ 无关，需 $x^2 + 2x - 3 = 0$，即 $x = 1$ 或 $x = -3$。此时 $y = 1$。

验证：$x = 1$：$y = a(0) + 1 = 1$ ✓；$x = -3$：$y = a(9 - 6 - 3) + 1 = 1$ ✓。

恒过两个定点 $\boxed{(1, 1) \text{ 与 } (-3, 1)}$。□

**方法提炼：** "过定点"的钥匙是**主元转换**：普通视角 $y$ 是 $x$ 的函数、$a$ 是参数；定点问题反过来——把 $a$ 当变量，令其系数为零。（本质：抛物线族 $y = a \cdot f(x) + g(x)$ 过 $f(x) = 0$ 上的所有点。）
:::

### 例 5（初中联赛风格）

已知抛物线 $y = x^2 - 2(m-1)x + m^2 - 2m$（$m$ 为实数）。

（1）证明：无论 $m$ 取何值，抛物线与 $x$ 轴总有两个不同的交点；
（2）求两交点间线段 $AB$ 的长度；
（3）求顶点坐标，并证明顶点在一条定直线上运动。

::: details 查看解答

**（1）** $\Delta = 4(m-1)^2 - 4(m^2 - 2m) = 4\big[(m^2 - 2m + 1) - (m^2 - 2m)\big] = 4 > 0$，恒有两不同交点。□

**（2）** 由弦长公式：$|AB| = \dfrac{\sqrt{\Delta}}{|a|} = \dfrac{2}{1} = \boxed{2}$（与 $m$ 无关——弦长不变量）。

**（3）** 顶点横坐标 $x_0 = m - 1$；代入（配方更快）：

$$y = x^2 - 2(m-1)x + m^2 - 2m = (x - m)^2 + 2x - 2m = (x-m)^2 + 2(x - m)$$

在顶点处 $x - m = -1$：$y_0 = 1 - 2 = -1$。顶点为 $(m-1,\ -1)$。

纵坐标恒为 $-1$ → 顶点在定直线 $\boxed{y = -1}$ 上运动。□

**方法提炼：** 三问一条龙：$\Delta$ 证存在 → 弦长公式得不变量 → 配方出顶点（含参配方时把 $x-m$ 当整体）。"参数消失、数值浮现"就是定点/定值问题的信号。
:::

### 例 6（经典赛题改编）

已知直线 $y = kx + b$ 与抛物线 $y = x^2 - 3x$ 交于 $A(1, y_1)$、$B(4, y_2)$ 两点。（1）求直线解析式；（2）求 $\triangle OAB$ 的面积（$O$ 为原点）。

::: details 查看解答

（1）$A(1, -2)$，$B(4, 4)$（代入抛物线）。直线过两点：$k = \dfrac{4 - (-2)}{4 - 1} = 2$，$b = -2 - 2 = -4$ → $y = 2x - 4$。

（2）**铅锤割补**：设直线交 $x$ 轴于 $M(2, 0)$（令 $y=0$）。

$$S_{\triangle OAB} = S_{\triangle OAM} + S_{\triangle OMB} = \frac12 |OM| \cdot |y_A| + \frac12 |OM| \cdot |y_B| = \frac12 \times 2 \times (2 + 4) = \boxed{6}$$

**方法提炼：** "斜三角形面积"标准解法：找直线与轴的交点当"分水岭"，拆成两个共底三角形，高就是两点的纵坐标绝对值。
:::

## 习题

1. 一次函数 $y = -2x + 3$ 的图象不经过第几象限？
2. 反比例函数 $y = \frac{k}{x}$ 的图象经过 $(2, -3)$，求 $k$ 并指出图象所在象限。
3. 求抛物线 $y = x^2 - 4x + 3$ 与 $x$ 轴交点 $A, B$ 及顶点 $C$，并求 $\triangle ABC$ 面积。
4. 解不等式：$-x^2 + 2x + 3 > 0$。
5. 已知抛物线 $y = x^2 + bx + 3$ 的对称轴为直线 $x = 1$，求 $b$ 与顶点坐标。
6. 求抛物线 $y = x^2 - (m+2)x + 2m$（$m$ 为参数）与 $x$ 轴交点，你能发现什么定值？
7. 直线 $y = kx + b$ 过点 $(1, 2)$ 与 $(-1, 6)$，求解析式并求它与两坐标轴围成的三角形面积。
8.（压轴）已知抛物线 $y = x^2 - 2(m-1)x + m^2 - 2m$（同例 5）。（1）求 $m$ 为何值时顶点位于 $x$ 轴下方且对称轴在 $y$ 轴左侧；（2）设抛物线与 $x$ 轴交于 $A, B$，与 $y$ 轴交于 $C$，当 $m = 1$ 时求 $\triangle ABC$ 的面积。

::: details 习题答案与提示

1. $k = -2 < 0$（过二、四方向），$b = 3 > 0$（交 $y$ 轴正半轴）→ 不过**第三象限**。
2. $k = 2 \times (-3) = \boxed{-6}$；$k<0$ → 图象在**二、四象限**。
3. $(x-1)(x-3) = 0$ → $A(1,0), B(3,0)$，顶点 $C(2, -1)$。面积 $= \frac12 \times 2 \times 1 = \boxed{1}$。
4. 乘 $-1$ 变向：$x^2 - 2x - 3 < 0 \Rightarrow \boxed{-1 < x < 3}$（开口向下取"两根之间"，别被负号骗）。
5. $-\frac{b}{2} = 1 \Rightarrow b = -2$；顶点 $(1, f(1)) = (1, 1 - 2 + 3) = \boxed{(1, 2)}$。
6. $x^2 - (m+2)x + 2m = (x - m)(x - 2)$：交点 $(m, 0)$ 与 $(2, 0)$——$(2, 0)$ 是**定点**；弦长 $|m - 2|$ 是变量，但"恒过 $(2,0)$"即定值信息。
7. $k = \frac{6-2}{-1-1} = -2$，$b = 4$ → $y = -2x + 4$。截距：$x$ 轴 $(2,0)$，$y$ 轴 $(0,4)$ → 面积 $\frac12 \times 2 \times 4 = \boxed{4}$。
8. (1) 顶点 $(m-1, -1)$ 恒在 $x$ 轴下方 ✓（纵坐标恒 $-1$）；对称轴 $x = m - 1 < 0 \Rightarrow \boxed{m < 1}$；(2) $m = 1$：$y = x^2 - 1$，$A(-1,0), B(1,0)$，$C(0, -1)$。面积 $= \frac12 \times 2 \times 1 = \boxed{1}$。
:::

## 本节方法小结

- 设解析式先看条件给的是**点、顶点还是零点**，选对形式省一半时间
- 弦长 $|x_1 - x_2| = \frac{\sqrt{\Delta}}{|a|}$：$\Delta$ 是定值则弦长是定值
- **过定点**：按参数整理、令参数系数为零；**顶点轨迹**：含参配方 + 消参
- 二次不等式图象法口诀：开口向上"大于两边、小于中间"（先化正 $a$）
- 斜三角形面积：**铅锤割补**，直线与轴交点当分水岭
