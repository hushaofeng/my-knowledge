# 第 4 章 一元二次方程与韦达定理

> 韦达定理的威力在于：**只谈根的对称信息，不必求出根**。竞赛里凡是"两根之和""两根之积""根的对称式"，一律先写韦达——这是一条肌肉记忆级的规则。

## 知识点精讲

### 1. 基本工具回顾

对 $ax^2 + bx + c = 0$（$a \ne 0$）：

$$\Delta = b^2 - 4ac, \qquad x_{1,2} = \frac{-b \pm \sqrt{\Delta}}{2a}$$

- $\Delta > 0$：两不等实根；$\Delta = 0$：两相等实根；$\Delta < 0$：无实根

### 2. 韦达定理

$$x_1 + x_2 = -\frac{b}{a}, \qquad x_1 x_2 = \frac{c}{a}$$

**使用前提：$\Delta \ge 0$（根存在）**。竞赛解答里"由韦达定理"之前先写"$\Delta \ge 0$"——这是阅卷人必看的检查点。

### 3. 对称式构造表（背熟，直接使用）

| 目标式 | 用和 $S$、积 $P$ 表示 |
|--------|---------------------|
| $x_1^2 + x_2^2$ | $S^2 - 2P$ |
| $(x_1 - x_2)^2$ | $S^2 - 4P$ |
| $x_1^3 + x_2^3$ | $S^3 - 3PS$ |
| $\dfrac{1}{x_1} + \dfrac{1}{x_2}$ | $\dfrac{S}{P}$ |
| $\dfrac{x_1}{x_2} + \dfrac{x_2}{x_1}$ | $\dfrac{S^2 - 2P}{P}$ |

### 4. 根的分布速查（充要条件）

| 条件 | 韦达翻译 |
|------|---------|
| 两根均为正 | $\Delta \ge 0$ 且 $S > 0$ 且 $P > 0$ |
| 两根均为负 | $\Delta \ge 0$ 且 $S < 0$ 且 $P > 0$ |
| 一正一负 | $P < 0$（**仅需此条**，$\Delta$ 自动 $> 0$） |
| 两根互为相反数 | $S = 0$ 且 $\Delta > 0$ |
| 一根为 0 | $P = 0$ |

"一正一负只需 $P<0$"的原理：$P = \frac ca < 0 \Rightarrow a, c$ 异号 $\Rightarrow \Delta = b^2 - 4ac > 0$ 自动成立。

## 经典例题

### 例 1（经典赛题改编）

已知方程 $x^2 + kx + 12 = 0$ 的两实根之差为 1，求 $k$。

::: details 查看解答

$S = -k$，$P = 12$。由对称式表：

$$(x_1 - x_2)^2 = S^2 - 4P = k^2 - 48 = 1 \Rightarrow k^2 = 49 \Rightarrow \boxed{k = \pm 7}$$

检验 $\Delta \ge 0$：$k^2 - 48 = 1 > 0$ ✓（两支都合法）。

**方法提炼：** "根的差"不能直接由韦达读出，先平方转成对称式 $(x_1-x_2)^2 = S^2 - 4P$。
:::

### 例 2（经典赛题改编）

已知 $x_1, x_2$ 是方程 $x^2 - 3x - 2 = 0$ 的两根，求 $x_1^3 + x_2^3$ 与 $\dfrac{x_1}{x_2} + \dfrac{x_2}{x_1}$。

::: details 查看解答

$S = 3$，$P = -2$。

$$x_1^3 + x_2^3 = S^3 - 3PS = 27 - 3 \times (-2) \times 3 = \boxed{45}$$

$$\frac{x_1}{x_2} + \frac{x_2}{x_1} = \frac{S^2 - 2P}{P} = \frac{9 + 4}{-2} = \boxed{-\frac{13}{2}}$$

**方法提炼：** 不解方程直接查表——韦达 + 对称式表 = 两行出答案。
:::

### 例 3（经典赛题改编）

$k$ 为何值时，方程 $x^2 - 4x + k = 0$ 的两根都是正数？

::: details 查看解答

三条件并列：

$$\Delta = 16 - 4k \ge 0 \Rightarrow k \le 4, \qquad S = 4 > 0 \ \checkmark, \qquad P = k > 0 \Rightarrow k > 0$$

综上 $\boxed{0 < k \le 4}$。

**方法提炼：** 正根三件套（$\Delta$、$S$、$P$）一个都不能省——只写 $P>0$ 是典型失分。
:::

### 例 4（经典赛题改编）

$m$ 为何值时，方程 $x^2 + (m - 2)x + m + 1 = 0$ 的两根一正一负？

::: details 查看解答

由速查表：一正一负 $\iff P < 0$：

$$m + 1 < 0 \Rightarrow \boxed{m < -1}$$

**判别式自动满足**：$m < -1$ 时 $\Delta = (m-2)^2 - 4(m+1) = m^2 - 8m = m(m-8)$，两个因子都负，$\Delta > 0$ ✓。

**方法提炼：** "一正一负"是韦达速查里最舒服的条件——积为负即可，$\Delta$ 不用管（当然答卷上说明一句"由 $P<0$ 知 $\Delta>0$"更稳）。
:::

### 例 5（经典赛题改编）

方程 $x^2 - 99x + c = 0$ 的两根都是质数，求 $c$。

::: details 查看解答

两质数之和为 99（奇数）。**质数中唯一的偶数是 2**——两个奇质数之和是偶数，不可能凑出奇和，所以一根必为 2。

另一根 $= 99 - 2 = 97$（是质数 ✓）。

$$c = 2 \times 97 = \boxed{194}$$

**方法提炼：** 质数 + 奇偶分析联手：奇和 ⟹ 含偶质数 2。这类"唯一偶质数"论证在数论模块（第 2 章例 2）出现过，现在有了韦达的 algebraic 外壳。
:::

### 例 6（初中联赛风格）

若 $x_1, x_2$ 是 $ax^2 + bx + c = 0$ 的两根，求以 $x_1 + k$ 与 $x_2 + k$ 为两根的一元二次方程。

::: details 查看解答

设新方程为 $y^2 - Sy' + P' = 0$ 的形式，其中

$$S' = (x_1 + k) + (x_2 + k) = (x_1 + x_2) + 2k = -\frac{b}{a} + 2k$$

$$P' = (x_1 + k)(x_2 + k) = x_1 x_2 + k(x_1 + x_2) + k^2 = \frac{c}{a} - \frac{bk}{a} + k^2$$

新方程：$y^2 - \left(2k - \dfrac{b}{a}\right) y + \left(k^2 - \dfrac{bk}{a} + \dfrac{c}{a}\right) = 0$，乘 $a$ 整理化：

$$\boxed{a y^2 + (2ak - b)\, y + \left(ak^2 - bk + c\right) = 0}$$

**方法提炼：** "造新方程"三板斧：新根的和与积（用韦达反向组装）→ 写 $y^2 - Sy + P = 0$ → 去分母。
:::

## 习题

1. 解方程 $x^2 - 6x + 8 = 0$，并用韦达定理检验。
2. 已知 $x^2 + px + 12 = 0$ 的两根之差为 2，求 $p$。
3. $k$ 为何值时，方程 $x^2 - 4x + k = 0$ 的两根都是负数？
4. 已知 $x_1, x_2$ 是 $x^2 - 5x + 3 = 0$ 的两根，求 $x_1^2 + x_2^2$ 与 $\dfrac{x_1}{x_2} + \dfrac{x_2}{x_1}$。
5. $k$ 为何值时，方程 $x^2 + (k+1)x + k = 0$ 的两根互为相反数？
6. 已知 $x_1, x_2$ 是 $x^2 - 4x + 2 = 0$ 的两根，求 $x_1^3 + x_2^3$ 与 $(x_1 - 1)(x_2 - 1)$。
7. 求整数 $k$，使方程 $x^2 + kx - 12 = 0$ 的两根均为整数，写出全部 $k$。
8.（压轴）已知关于 $x$ 的方程 $x^2 - (m-3)x + m = 0$。（1）当 $m$ 为何值时，方程有两个不相等的实数根？（2）若两根之差的平方等于 13，求 $m$。

::: details 习题答案与提示

1. $(x-2)(x-4) = 0$ → $x = 2, 4$。检验：和 $6 = -(-6)$ ✓，积 $8$ ✓。
2. $(x_1-x_2)^2 = S^2 - 4P = p^2 - 48 = 4 \Rightarrow p^2 = 52$，$\Delta = p^2 - 48 = 4 > 0$ ✓。答案 $p = \pm 2\sqrt{13}$。
3. 三条件：$\Delta = 16 - 4k \ge 0$，$S = 4 > 0$ ✗——**和必须为负**，但本题 $S = 4$ 恒正 → **无解**（两根不可能都是负数；这正是"三件套一个不能省"的反面教材）。
4. $S = 5, P = 3$：$x_1^2+x_2^2 = 25 - 6 = \boxed{19}$；$\frac{x_1}{x_2}+\frac{x_2}{x_1} = \frac{25-6}{3} = \boxed{\dfrac{19}{3}}$。
5. 相反数 ⟺ $S = -(k+1) = 0$ 且 $\Delta > 0$：$k = -1$，方程 $x^2 - 1 = 0$，$\Delta = 4 > 0$ ✓。答案 $k = -1$。
6. $S = 4, P = 2$：$x_1^3 + x_2^3 = 64 - 3 \times 2 \times 4 = \boxed{40}$；$(x_1-1)(x_2-1) = P - S + 1 = 2 - 4 + 1 = \boxed{-1}$。
7. 整数根 ⟹ 整数积 $-12 = x_1 x_2$ 且 $k = -(x_1+x_2)$。因子对（异号）：$(1,-12)\to k=11$；$(2,-6)\to 4$；$(3,-4)\to 1$；$(12,-1)\to -11$；$(6,-2)\to -4$；$(4,-3)\to -1$。$k \in \{\pm 11, \pm 4, \pm 1\}$。
8. (1) $\Delta = (m-3)^2 - 4m = m^2 - 10m + 9 = (m-1)(m-9) > 0 \Rightarrow \boxed{m < 1 \text{ 或 } m > 9}$；(2) $(x_1-x_2)^2 = S^2 - 4P = (m-3)^2 - 4m = 13 \Rightarrow m^2 - 10m - 4 = 0 \Rightarrow m = 5 \pm \sqrt{29}$。检验 $\Delta = 13 > 0$ ✓，答案 $m = 5 \pm \sqrt{29}$。
:::

## 本节方法小结

- 见"两根之差"先**平方**转对称式；见"和、积"直接查表
- 正根/负根三件套（$\Delta, S, P$）缺一不可；**一正一负只需 $P<0$**
- 韦达使用前提 $\Delta \ge 0$：解答里必须出现，且**最后要代回检验**
- 质数根 + 奇偶分析：奇和必含偶质数 2
- 造新方程 = 新和与新积 → $y^2 - Sy + P = 0$
