# 第 6 章 逻辑推理与图论初步

> 组合模块的收官双主题：**逻辑推理**（假设、排除、列表）与**图论初步**（点、边、度）。两者的交汇点是"把语言叙述翻译成数学结构"——这是整部教程训练的终极能力。

## 知识点精讲

### 1. 逻辑推理三板斧

- **假设法**：假设某人说真话 → 逐句推导 → 矛盾则换假设（真假话问题标配）
- **排除法**：由最强约束（信息量最大的陈述）先排除
- **列表法**：多对象多属性 → 画表格打钩打叉（√ / ×），交叉排除

### 2. 图论基本语言

**图** $G$ = 若干**顶点**（点）+ 若干**边**（连接两点的线）。顶点 $v$ 的**度** $d(v)$ = 与它相连的边数。

### 3. 握手定理（图论第一恒等式）

所有顶点度数之和 = 边数的 2 倍：

$$\sum_v d(v) = 2|E|$$

（每条边恰好给两个端点各贡献 1 度。）

**两条推论**：①度数和必为偶数（"奇度点"必偶数个）；②$n$ 人聚会必有两人握手次数相同（度数 0 与 $n-1$ 不能共存 → 至多 $n-1$ 种度数，$n$ 个人 → 抽屉原理）。

### 4. 一笔画（欧拉路径）判定

连通图能一笔画 $\iff$ **奇度点的个数为 0 或 2**（0 个：回到起点；2 个：从一个奇点画到另一个奇点）。

### 5. 完全图

$n$ 个点两两连边（记 $K_n$）：边数 $= \dbinom n2 = \dfrac{n(n-1)}2$（与第 1 章组合数会师）。

## 经典例题

### 例 1（经典赛题改编·真假话）

甲、乙、丙三人中只有一人说真话。甲说："乙在说谎。"乙说："丙在说谎。"丙说："甲和乙都在说谎。"问谁说真话？

::: details 查看解答

**逐一假设**：

- 假设**甲真**：乙谎 → "丙在说谎"为假 → 丙真。此时甲、丙都真——与"只有一人说真话"矛盾 ✗
- 假设**丙真**：甲、乙都谎 → 甲说"乙谎"为假 → 乙真，矛盾 ✗
- 假设**乙真**：丙谎 → "甲和乙都在说谎"为假 → 甲真或乙真（乙真 ✓ 成立）；甲谎 → "乙在说谎"为假 → 乙真 ✓ 一致。真话者：乙，说假话：甲、丙 ✓ 自洽

**乙说真话**。

**方法提炼：** 真假话问题的假设顺序按"信息量"排——丙的话约束两人（最强），先验丙常最快排除；每个假设都要**检查所有人的话**，而不是只查被假设者。
:::

### 例 2（经典赛题改编·列表法）

甲、乙、丙三人，一位是教师、一位是医生、一位是警察。已知：①甲比教师年龄大；②丙与医生不同岁；③医生比乙年龄小。判断各人的职业。

::: details 查看解答

由 ①③：甲、乙都不是教师 → **丙是教师**。

由 ②：丙不是医生（一致）。由 ③：乙不是医生 → **乙是警察**，**甲是医生**。

验证年龄链：丙（教师）与医生（甲）不同岁 ✓；医生甲比乙小 ✓；甲比教师丙大 ✓；医生甲 < 警察乙，教师丙 < 医生甲——全部相容 ✓。

**答案：甲是医生，乙是警察，丙是教师。**

**方法提炼：** 三条线索各排除一个组合——"比…大/小"类条件同时传递**职业排除**与**年龄排序**两路信息，双路夹击出唯一解。
:::

### 例 3（经典赛题改编·握手定理）

某次会议上部分学者两两握手。证明：握了奇数次手的人有偶数个。

::: details 查看解答

建图：学者 = 顶点，一次握手 = 一条边。每人握手次数 = 其顶点的度。

$$\sum_v d(v) = 2|E| \text{ 为偶数}$$

度数和 = 奇度点贡献 + 偶度点贡献 = 奇度点个数 × 奇数 + 偶数。要总和为偶 → **奇度点个数为偶数**。$\blacksquare$

**方法提炼：** 握手定理 = "度数和为偶"这一个事实。任何"次数之和/奇偶"问题先想它。
:::

### 例 4（经典赛题改编·一笔画）

下图（文字描述）：房间问题——一个园丁要给花园的小路修整，花园地图抽象为图：顶点 $A, B, C, D$ 与桥 $E$，边为 $AB, AC, BC, BD, CD, AE, DE$（$E$ 在 $BC$ 中间：$B-E-C$）。能否不重复地走遍所有边？

::: details 查看解答

计算各点度数：

- $d(A) = 2$（$AB, AC$）
- $d(B) = 3$（$BA, BC, BE$）
- $d(C) = 3$（$CA, CB, CE$）
- $d(D) = 2$（$DB, DC$）
- $d(E) = 2$（$EB, EC$）

奇度点：$B, C$ 恰好 2 个 → **可以一笔画**，从 $B$ 出发到 $C$ 结束（或反向）。

一条可行路线：$B \to E \to C \to A \to B \to C \to D \to B$？逐步验证边：$BE$✓ $EC$✓ $CA$✓ $AB$✓ $BC$✓ $CD$✓ $DB$✓——7 条边各走一次 ✓。$\blacksquare$

**方法提炼：** 一笔画两步：数奇点（0 或 2 才可行）→ 从奇点出发。**七桥问题的教训**：4 个奇点 → 不可能，欧拉由此开创图论。
:::

### 例 5（经典赛题改编·完全图）

10 名同学两两握一次手，共握手多少次？若其中"互相认识的 3 人小组"（三人两两都认识）最多有多少种？

::: details 查看解答

握手次数 $= \dbinom{10}{2} = \dfrac{10 \times 9}{2} = \boxed{45}$。

"三人两两认识" = 图中的三角形。$K_{10}$ 的三角形总数：每 3 点构成一个 →

$$\dbinom{10}{3} = 120$$

若只问"任意挑 3 人两两认识"的最大可能——当 10 人两两都认识（完全图）时，三角形 $= \dbinom{10}3 = \boxed{120}$ 个。

**方法提炼：** 完全图 $K_n$ 的边数 $\binom n2$、三角形数 $\binom n3$——组合数在图上的直接化身。
:::

### 例 6（初中联赛风格·帽子推理）

三顶红帽子、两顶白帽子，给甲、乙、丙三人各戴一顶（各人只能看到别人的帽子）。按甲、乙、丙顺序问"知道自己帽子的颜色吗？"甲答"不知道"，乙答"不知道"，丙答"知道了"。丙戴的是什么颜色的帽子？

::: details 查看解答

白帽只有 2 顶。

**甲答"不知道"** → 甲看到的乙、丙帽子**不都是白色**（否则甲戴红——只剩红帽）→ 乙、丙至少一人红。

**乙答"不知道"**：乙听到甲的话。若乙看到**丙戴白** → 由甲的结论"乙丙至少一红" → 乙自己红 → 乙应答"知道"。乙答"不知道" → **丙戴红**（乙看到丙红，无法确定自己）✓

**丙答"知道了"**：丙正是通过上述两步推理知道自己戴**红帽**。

$$\boxed{\text{丙戴红帽子}}$$

**方法提炼：** 帽子问题的推理链 = **前一个人的"不知道"也是信息**。每一层"不知道"都排除一种配置，逐层收缩——这是"公共知识"推理的入门。
:::

## 习题

1. 甲、乙、丙、丁四人中只有一人打碎了花瓶，只有一人说真话。甲说："是乙。"乙说："是丁。"丙说："我没有打碎。"丁说："乙在说谎。"问谁打碎了花瓶，谁说了真话？
2. 5 人聚会，证明必有两人握手的次数相同。（提示：度数 0 与 4 不能共存）
3. 某图中所有顶点度数都是 3（三次图），且顶点数为 10。求边数。
4. 一个图的度数序列为 1, 2, 2, 3, 4？改为：度数序列 $(1, 2, 2, 3)$ 的图存在吗？说明理由。
5. $K_6$（6 点完全图）有多少条边、多少个三角形？
6. 一次聚会 9 人，每人恰与其他 3 人握手。共握手多少次？
7. 甲、乙、丙、丁、戊五人参加百米赛跑（无并列）。名次线索：①甲不是第一；②乙不是最后；③丙的名次紧挨在甲后面；④丁比戊靠前两位？改为唯一可解版：①甲比乙快；②丙第三；③丁比甲快；④戊比乙快但比甲慢。写出完整名次。（提示：由②③④夹出甲的位置）
8.（压轴·拉姆齐定理入门）证明：任意 6 个人中，必有 3 人互相认识，或 3 人互相不认识。（用认识/不认识两种颜色的边染完全图 $K_6$，取一人观察他连出的 5 条边）

::: details 习题答案与提示

1. 逐一假设真话者：①若甲真（是乙）→ 乙谎（不是丁，一致）→ 但丙"我没有打碎"为真（打碎者是乙）→ 两真 ✗；②若乙真（是丁）→ 甲谎、丙"我没有打碎"为真 → 两真 ✗；③若丙真（不是丙）→ 甲谎 → 不是乙；乙谎 → 不是丁 → 打碎者是甲或丙，丙真排除丙 → 是甲；但丁"乙在说谎"也为真（乙确实谎）→ 两真 ✗；④若丁真 → 甲谎 → 不是乙；乙谎 → 不是丁；丙谎 → **是丙**；甲、乙、丙说假话，丁说真话 ✓ 完全自洽。**答案：丙打碎花瓶，丁说了真话**。□
2. 度数只能取 $0,1,2,3,4$。若有两人度数相同之外的组合——5 人 5 个不同度数需取遍 $\{0,1,2,3,4\}$，但度 4（与所有人握手）与度 0（与无人握手）不能共存 → 至多 4 种度数 → 5 人中必有两人相同（抽屉原理）。
3. $\sum d = 3 \times 10 = 30 = 2|E|$ → $|E| = \boxed{15}$ 条。
4. 度数和 $1+2+2+3 = 8$ = 2|E| → 边数 4（偶数 ✓ 初判可行）；具体构造：路径图 $A-B-C-D$ 加边 $B-C$？度数：$A:1, B:2, C:2, D:1$——序列 $(1,2,2,1)$ 不符。改：三角形 $B,C,D$ + 尾巴 $A-B$：$d(A)=1, d(B)=2, d(C)=2, d(D)=2$ → $(1,2,2,2)$ ✗。构造 $(1,2,2,3)$：顶点 $v$ 度 3 连向度 1、2、2 各点 → 度 1 点只连 $v$ ✓ 度 2 点各再需 1 条边 → 两点互连 ✓：边 $vx, vy, yz? $ 设点 $p(3), a(1), b(2), c(2)$：边 $pa, pb, pc, bc$：$d(p)=3 ✓, d(a)=1 ✓, d(b)=2 ✓, d(c)=2 ✓$ → **存在**。
5. $K_6$：边 $\dbinom62 = \boxed{15}$，三角形 $\dbinom63 = \boxed{20}$。
6. $\sum d = 9 \times 3 = 27 = 2|E|$ → $|E| = 13.5$ ✗ **不存在这样的聚会**（握手定理的奇偶检验：3×9 为奇数）→ 答案：不可能。（本题训练"先检验再计算"）
7. 由②丙第三；③丁比甲快 → 丁在前两名；④戊比乙快比甲慢 → 戊在甲、乙之间。甲比乙快 → 甲>乙。若甲第四 → 戊第五、乙第六 ✗（只有 5 人）→ 甲第二？则丁第一，戊在 2、3 之间？戊比甲慢 → 戊 ∈ {4,5}，乙在戊后 → 乙 5、戊 4 → 名次：丁、甲、丙、戊、乙 ✓ 全部条件满足。**名次：丁、甲、丙、戊、乙**。
8. 取一人 $A$：他与其余 5 人有 5 条关系边，每边染"认识"或"不认识"两色 → 由抽屉原理至少 3 条同色（设为"认识"，另一情形对称）。设 $B, C, D$ 三人与 $A$ 互相认识。看 $B, C, D$ 之间的三条边：若有一条"认识"（如 $BC$）→ $A, B, C$ 三人两两认识 ✓；若三条全"不认识" → $B, C, D$ 互相不认识 ✓。两分支必居其一。$\blacksquare$
:::

## 本节方法小结

- 真假话：**假设 + 全面核查**；先验约束最强的陈述
- 多属性匹配：**列表打叉**，从唯一候选处破局
- 握手定理 $\sum d = 2|E|$：奇偶检验是"图存在性"的第一道闸（**度数和为奇 → 图不存在**）
- 一笔画：奇点数 0 或 2；完全图 $K_n$：边 $\binom n2$、三角形 $\binom n3$
- 帽子问题：**"不知道"也是信息**，逐层收缩配置空间
- 拉姆齐 $R(3,3) = 6$：两色抽屉 + 收缩——第 2 章抽屉原理在图上的终极演出
