# 第 2 章 抽屉原理

> 抽屉原理（鸽笼原理）是**存在性证明**的第一武器：它不告诉你"谁和谁"，只保证"一定存在"。题目的全部难度在于——**怎么造抽屉**。原理一句话就懂，造抽屉是门手艺。

## 知识点精讲

### 1. 基本形式

$$n + 1 \text{ 个物体放入 } n \text{ 个抽屉} \Rightarrow \text{必有一个抽屉至少含 } 2 \text{ 个物体}$$

**加强形式**：$mn + 1$ 个物体放入 $n$ 个抽屉 → 必有一个抽屉至少 $m + 1$ 个物体。

反向叙述（最不利原则）："保证 $\cdots$" 的问题问的是最倒霉情况下仍成立的最小数量。

### 2. 造抽屉的四大思路

| 思路 | 示例 |
|------|------|
| **按余数分类** | 整除 $n$ 的余数类 = $n$ 个抽屉 |
| **按性质配对** | 和为定值的数对、互逆对 |
| **按"化简后标准形"** | 每个 $= 2^k \times$ 奇数（奇数部分作抽屉） |
| **分割图形** | 大图形切成小区域，区域作抽屉 |

### 3. 证明存在性/不可能性的标准句式

> 构造 $n$ 个抽屉 → $n+1$ 个对象入抽屉 → 某抽屉 ≥ 2 个对象 → 翻译该抽屉的"共同性质" → 得证。

## 经典例题

### 例 1（经典赛题改编）

某班有 13 名学生。证明：其中必有 2 人出生在同一个月。

::: details 查看解答

12 个月 = 12 个抽屉，13 名学生 = 13 个物体。$13 > 12$ → 某月至少 2 人。$\blacksquare$

**方法提炼：** 最简形态。抽屉是"月份"，物体是"人"——明确**谁是抽屉谁是物体**是写证明的第一句。
:::

### 例 2（经典赛题改编）

证明：任取 $n + 1$ 个整数，其中必有两个数之差能被 $n$ 整除。

::: details 查看解答

按除以 $n$ 的**余数分类**：全体整数分为 $n$ 类（余 $0, 1, \dots, n-1$）——$n$ 个抽屉。

$n + 1$ 个整数放入 $n$ 类 → 必有两个数 $a, b$ 同余：$a \equiv b \pmod n$ → $n \mid (a - b)$。$\blacksquare$

**方法提炼：** "余数作抽屉"是使用频率第一的构造——第 1 章（整除）与本章在这里会师。
:::

### 例 3（经典赛题改编·最不利原则）

一副扑克牌 54 张（4 种花色各 13 张，外加 2 张王牌）。至少抽取多少张，才能**保证**有 5 张牌花色相同？

::: details 查看解答

**最不利情形**：4 个花色各取 4 张（$16$ 张）+ 2 张王牌（花色不定）= 18 张，仍然没有 5 张同花色。

再抽 1 张（第 19 张）必是某花色 → 该花色已有 5 张。

$$\boxed{19 \text{ 张}}$$

**方法提炼：** "保证" = 最不利 + 1。每个抽屉都喂到"差 1 张达标"，再补 1 张。
:::

### 例 4（经典赛题改编·分割图形）

在边长为 1 的等边三角形内（含边界）任意放 5 个点。证明：必有两点距离不超过 $\dfrac12$。

::: details 查看解答

连接三条中位线，把大三角形分成 **4 个边长 $\frac12$ 的等边小三角形**——4 个抽屉。

5 个点 → 某个小三角形内含 ≥ 2 点。小三角形内任意两点距离 ≤ 其边长 $\frac12$。$\blacksquare$

**方法提炼：** 图形抽屉 = **切分后每块"直径"可控**。一般规律：$k^2$ 个点放边长 1 的正方形/三角形，切 $k^2$ 块 → 两点距离 ≤ $\frac{\sqrt2}{k}$（正方形）或 $\frac1k$（等边三角形）。
:::

### 例 5（经典赛题改编·配对抽屉）

从 1 到 10 中任取 6 个不同的数。证明：其中必有两数之和为 11。

::: details 查看解答

配对：$(1,10), (2,9), (3,8), (4,7), (5,6)$——5 对"和为 11"的数对，5 个抽屉。

6 个数放入 5 对 → 某一对**两个数都被取到** → 和为 11。$\blacksquare$

**方法提炼：** 抽屉不必是"类别"，**数对也是抽屉**——抽屉内"同时出现"就是目标性质。构造前先问：目标性质（和为 11）由哪些"小组"承载？
:::

### 例 6（初中联赛风格·化标准形）

从 1 到 100 中任取 51 个不同的数。证明：其中必有一个数是另一个数的倍数。

::: details 查看解答

**化标准形**：任何正整数都能唯一写成 $2^k \times q$（$q$ 为奇数）——提出全部因数 2。

1~100 中的奇数恰有 50 个（1, 3, 5, …, 99）→ 50 个抽屉（按奇数部分 $q$ 分类）。

51 个数 → 两个数奇数部分相同：$a = 2^{k_1} q$，$b = 2^{k_2} q$。

不妨 $k_1 < k_2$，则 $b = a \cdot 2^{k_2 - k_1}$ → **$b$ 是 $a$ 的倍数**。$\blacksquare$

**方法提炼：** "**提炼标准形**"是本章最高级的构造：把无限多样的对象压缩到有限个等价类（这里 100 个数压成 50 类），倍数关系立刻显形。取 $n + 1$ 个数从 $\{1, \dots, 2n\}$ 中 → 有倍数关系，是本题的一般形式。
:::

## 习题

1. 某校有 370 名学生，证明必有 2 人同一天过生日。
2. 证明：任意 5 个整数中，必有 3 个数之和能被 3 整除。（提示：按 mod 3 余数分类，讨论"某类有 3 个""某类有 2 个""各类至多 1 个（即 2+2+1）"……按 5 个数的余数分布分类讨论）
3. 口袋中有红、黄、蓝三种颜色的球各 10 个（充分混合）。至少取多少个球才能保证有 4 个同色？
4. 边长为 2 的正方形内任放 5 个点，证明必有两点距离 $\le \sqrt2$。
5. 从 1 到 20 中任取 11 个不同的数，证明必有两数之差为 10。
6. 从 1 到 100 中任取 51 个数，证明必有两数之差为 1？——改为：证明必有两数，其中一个是另一个的 2 倍？不行（51 个奇数无此性质）。**定题**：从 1 到 100 的奇数（共 50 个）中任取 26 个，证明必有两数之和为 100。（提示：配对 $(1,99), (3,97), \dots, (49,51)$ 共 25 对）
7. 从 1 到 200 中任取 101 个不同的数，证明其中必有一个数是另一个数的倍数。
8.（压轴）17 名学生两两通信，每两人之间恰好讨论 3 个话题（甲、乙、丙）中的一个。证明：必存在 3 名学生，他们两两讨论的是同一个话题。（提示：取学生 $S$，他发出的 16 封信按话题分 3 类 → 至少 6 封同话题，收信人记为 $A_1, \dots, A_6$；再对 $A_1, \dots, A_6$ 之间的通信用反证/抽屉收缩到 3 人）

::: details 习题答案与提示

1. 一年至多 366 天 = 366 个抽屉，$370 = 366 + 4 > 366$ → 某天至少 2 人。
2. 按 mod 3 余数分 3 类讨论：①某类 ≥ 3 个 → 这 3 个余数相同，和 $\equiv 3r \equiv 0 \pmod 3$；②各类都 ≤ 2 且总数 5 → 分布必为 (2,2,1) → **每类都非空** → 各取一个：$0 + 1 + 2 \equiv 0 \pmod 3$。两分支覆盖所有情形。□
3. 最不利：三色各 3 个 = 9 个；再取 1 个 → 第 10 个使某色达 4。答案 $\boxed{10}$。
4. 切成 4 个 $1 \times 1$ 小正方形（4 抽屉），5 点 → 某格 ≥ 2 点，格内两点距离 $\le$ 对角线 $\sqrt2$。
5. 配对 $(1,11), (2,12), \dots, (10,20)$ 共 10 对，11 个数 → 某对全取 → 差 10。
6. 1~100 的奇数配对：$(1,99), (3,97), \dots, (49,51)$ 共 25 对，26 个数 → 某对全取 → 和为 100。
7. 每个 $n \in [1, 200]$ 写成 $2^k q$（$q$ 奇数），1~200 的奇数共 100 个 = 100 抽屉；101 个数 → 两个同奇部 → 大的是小的的倍数。
8. 取 $S$：16 封信按 3 话题分类，$\lceil 16/3 \rceil = 6$ → 至少 6 人（记 $A_1,\dots,A_6$）与 $S$ 讨论同一话题（设为甲）。若 $A_1,\dots,A_6$ 中有两人互相讨论甲 → 这两人与 $S$ 构成"全甲"三人组，得证。否则 $A_1,\dots,A_6$ 两两之间只讨论乙或丙。取 $A_1$：他发给其余 5 人（$A_2,\dots,A_6$）的信只用乙/丙 → 至少 3 封同话题（设乙），收信人 $B_1, B_2, B_3$。若 $B_1,B_2,B_3$ 中有两人讨论乙 → 与 $A_1$ 构成全乙三人组；否则他们两两只能讨论丙 → $B_1, B_2, B_3$ 两两全丙，得证。所有分支覆盖 → 必存在同话题三人组。□
:::

## 本节方法小结

- 抽屉原理 = **存在性证明的标准件**：造抽屉 → 放物体 → 翻译共同性质
- 四大构造：**余数类、配对（和/差定值）、化标准形（$2^k q$）、分割图形**
- "保证"问题 → **最不利 + 1**：每个抽屉喂到差一张，再补一张
- 图形抽屉：切分后**每块直径**就是距离上界
- "至少 $r$ 个同组"加强式：$n(r-1) + 1$ 个物体、$n$ 个抽屉
- 压轴级题目：抽屉 + **分类讨论收缩**（17 人三话题是拉姆齐理论的入门门砖）
