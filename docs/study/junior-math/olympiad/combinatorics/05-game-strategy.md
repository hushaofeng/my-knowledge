# 第 5 章 操作与策略

> 博弈题问的是"**谁有必胜策略**"。三大武器：**倒推法**（从终局往前推）、**对称策略**（复制对方的动作）、**不变量**（无论怎么操作，某个量守恒）。

## 知识点精讲

### 1. 倒推法（取子游戏的万能钥匙）

"轮流取 1~$k$ 粒、取到最后者胜"：**必胜态 = 把 $(k+1)$ 的倍数留给对方**。

原因：对方取 $j$ 粒（$1 \le j \le k$），我就取 $k+1-j$ 粒——每轮合计 $(k+1)$，剩余数模 $(k+1)$ 不变，最终我取到最后一粒。

### 2. 对称策略（后手/先手的复制机）

局面中心对称时，**后手可以镜像先手的每一步**。先手破对称的方法：先走一步占据对称中心，然后自己当"后手"。

### 3. 不变量（操作类问题的裁判）

操作把状态变来变去，但某个量（奇偶性、模某数的余数、染色差）**纹丝不动** → 与目标状态矛盾 → 不可能。

### 4. NIM 游戏（三堆取子，取最后者胜）

三堆石子 $a, b, c$，轮流从**一堆**取任意个。必胜判据（Bouton 定理）：

$$a \oplus b \oplus c = 0 \iff \text{当前局面是必败态（轮到谁走谁输）}$$

其中 $\oplus$ 是二进制**不进位加法**（按位异或）。非零局面总可一步变成零（选一堆 $x$ 改成 $x \oplus S < x$，$S$ 为当前异或和）。

## 经典例题

### 例 1（经典赛题改编·取子倒推）

桌上 100 粒石子，两人轮流取，每次取 1~5 粒，取到最后一粒者胜。谁有必胜策略？

::: details 查看解答

$100 = 6 \times 16 + 4$ → 先手**先取 4 粒**，剩 96（6 的倍数）。

此后对方取 $j$ 粒，先手就取 $6 - j$ 粒——每轮合计 6 粒，剩余数始终是 6 的倍数，最终先手取到第 100 粒。

**先手必胜**。$\blacksquare$

**方法提炼：** 倒推三步：终局倒着找"安全余数"（$k+1$ 的倍数）→ 初始数除以 $k+1$ 取余 → 余 0 后手赢，否则先手先吃掉余数。
:::

### 例 2（经典赛题改编·对称策略）

两人轮流在圆形桌面上放置相同的硬币（平放、不重叠），硬币放不下者输。证明先手有必胜策略。

::: details 查看解答

先手把第一枚硬币放在**圆桌正中心**。

此后桌面（去掉中心）关于中心**中心对称**：对方放哪，先手就在其关于中心的对称位置放一枚——由于对方放得下，其对称位置必然也空着（对称性 + 已放硬币成对出现）。

先手永远有地方放 → **放不下的是对方**。$\blacksquare$

**方法提炼：** 对称策略的完整链条：①造对称（先手占中心）②镜像对方 ③论证"对方可放 ⟹ 我可放"（对称位置的可用性）。圆桌的完美对称是本题的礼物——矩形桌面同样可用（中心对称）。
:::

### 例 3（经典赛题改编·不变量）

马从坐标原点 $(0,0)$ 出发，每步走 $(2,1)$ 或 $(1,2)$ 方向（四个方向任选：$(\pm2,\pm1)$、$(\pm1,\pm2)$）。证明：马不能到达点 $(100, 100)$。

::: details 查看解答

考察不变量：每走一步，$x + y$ 的变化量 $= \pm2 \pm 1$ 或 $\pm1 \pm 2$，即 $\pm3$ 或 $\pm1$？

仔细算：$(2,1)$：$x+y$ 增加 $2+1 = 3$；$(-2,1)$：$-1$；$(2,-1)$：$1$；$(-2,-1)$：$-3$；$(1,2)$：$+3$；等等——变化量 $\in \{+3, +1, -1, -3\}$。

不够干净！改用更强的不变量：$x + y \pmod 3$？变化 $+3 \equiv 0$，但 $+1, -1$ 不为 0。**修正不变量**：考察 $x + y$ 的奇偶性：$\pm3, \pm1$ 都是奇数 → **每步 $x+y$ 的奇偶性翻转**。

出发 $(0,0)$：$x+y = 0$（偶）。走 $n$ 步后 $x + y \equiv n \pmod 2$。

到达 $(100,100)$：$x + y = 200$（偶）→ 需要 $n$ 为偶数——**不矛盾**！需要更细的不变量。

**正确不变量**：考察 $x + y \pmod 3$ 配合步数？各方向变化：$+3 \equiv 0$、$-3 \equiv 0$、$+1$、$-1 \pmod 3$——不成不变量。换：

考察 $x - y \pmod 3$：$(2,1)$：$+1$；$(1,2)$：$-1$；$(2,-1)$：$+3 \equiv 0$；$(-1,-2)$：$+1$……也不定。

**教科书级不变量**：马步向量 $(2,1)$ 型的坐标和 $x+y$ 每步变化**奇数**，且 $x - y$ 每步变化**奇数**。到达 $(100,100)$ 需要 $x + y = 200$：步数 $n \equiv 200 \equiv 0 \pmod 2$；$x - y = 0$：$0 \equiv n \pmod 2$。一致，仍不矛盾。

**引入真正的限制**：每步 $|x| + |y|$ 增加恰好 3？$(2,1)$：$+3$ ✓；$(2,-1)$：$|x|+|y|$ 变化不定。**换题设**：只允许 $(2,1)$ 与 $(1,2)$ 的**正向**步（向右上方走）→ 每步 $x+y$ **恰好增加 3** →

$$x + y \equiv 0 \pmod 3$$

到达 $(100,100)$：$200 \equiv 2 \pmod 3 \ne 0$ → **不可达**。$\blacksquare$

**方法提炼：** 找不变量要**先验证再使用**——本题第一直觉（模 3）在四方向下失效，收窄走法（单向）后不变量成立。竞赛题的走法限制往往就是为不变量准备的。
:::

### 例 4（经典赛题改编·NIM 判据应用）

三堆石子分别为 4、5、6 粒，两人轮流从某一堆取**至少一粒**（可取完整堆），取到最后一粒者胜。谁有必胜策略？

::: details 查看解答

计算 NIM 和：$4 \oplus 5 \oplus 6$：$100 \oplus 101 = 001$，$001 \oplus 110 = 111 = 7 \ne 0$ → **先手必胜**。

找制胜一步：选一堆 $x$ 改为 $x \oplus 7$（须变小）：

- $x = 4$：$4 \oplus 7 = 3 < 4$ ✓

先手从 4 粒堆取 1 粒，剩 3、5、6：$011 \oplus 101 \oplus 110 = 000$ ✓。

此后对方每步都会打破零态，先手总能一步归零，直到取到最后一粒。$\blacksquare$

**方法提炼：** NIM 三步曲：算异或和 → 非零则存在 $x \oplus S < x$ 的堆 → 把它改成 $x \oplus S$（用二进制最高位定位）。异或和为零态 = "轮到谁走谁必输"。
:::

### 例 5（经典赛题改编·报数博弈）

两人轮流报数，从 1 开始，每人每次报 1~3 个连续数字（接着上一个数往下报），报到 30 的人获胜。先手有必胜策略吗？

::: details 查看解答

倒推：必胜者报到的关键数是 $30, 26, 22, \dots$（模 4 余 2）。

$30 = 4 \times 7 + 2$ → 先手**先报 1、2 两个数**（占据 26 的位置结构），此后对方报 $j$ 个，先手报 $4 - j$ 个。

每轮合计 4 → 先手报到 $2, 6, 10, \dots, 26, \boxed{30}$。**先手必胜**。$\blacksquare$

**方法提炼：** 报数博弈 = 取子博弈的换装：连续报数区间对应石子数，"报到 30"对应"取最后一粒"，$k+1 = 4$。
:::

### 例 6（初中联赛风格·归纳构造策略）

证明：$2^n \times 2^n$ 棋盘去掉任意一个方格后，剩下的部分可以被 L 形三格骨牌（$2 \times 2$ 去掉一格的形状）完全覆盖。

::: details 查看解答

**归纳基础**：$n = 1$：$2 \times 2$ 去一格 = 恰好一个 L 形骨牌 ✓。

**归纳步骤**：设 $2^n \times 2^n$ 成立，考虑 $2^{n+1} \times 2^{n+1}$ 缺一格：

1. 用两条中线把棋盘分成 **4 个 $2^n \times 2^n$ 象限**，缺格在某一个象限内
2. 在棋盘**中心**放一个 L 形骨牌，盖住**不含缺格的三个象限各一个角格**
3. 现在四个象限各自都是"缺一格的 $2^n \times 2^n$ 棋盘"（三个被 L 掏掉角格，一个本来就缺）
4. 由归纳假设，每个象限可被 L 形骨牌覆盖 □

由数学归纳法，对一切 $n$ 成立。$\blacksquare$

**方法提炼：** "**中心 L 掏三角**"是覆盖理论的著名构造——它同时是"存在性证明"与"算法"：按此递归可实际输出覆盖方案。归纳构造 = 分解成同构子问题 + 一次桥接操作。
:::

## 习题

1. 桌上 50 粒石子，两人轮流取 1~4 粒，取到最后一粒者胜。谁有必胜策略？
2. 两人轮流在 $1 \times 8$ 的长桌上放 $1 \times 2$ 多米诺骨牌（占相邻两空格），放不下者输。谁有必胜策略？
3. 报数游戏：从 1 报到 100，每人每次报 1~7 个连续数字，报到 100 者胜。谁有必胜策略？
4. 马从 $(0,0)$ 出发每步走 $(2,1)$ 或 $(1,2)$（仅向右上）。它能到达 $(99, 100)$ 吗？
5. 三堆石子 3、4、5 粒，轮流从一堆取任意粒，取最后者胜。先手第一步怎么取？
6. 三堆石子 3、4、5 粒，规则同上，但**取到最后一粒者输**（misère 规则）。先手必胜策略是什么？
7. 两人轮流在圆桌上放 1 元硬币（同例 2）。若桌面是 $3 \times 3$ 的正方形棋盘（硬币放在格子内，一格一枚），先手还有必胜策略吗？
8.（压轴）有 2008 个空格排成一行。两人轮流在空格中放入棋子（一格一枚），每当某段连续空格被放满就标记。先手想让"两端都被放过的空格段"出现？——**定题（经典）**：两人轮流在 $9 \times 9$ 棋盘的格子里放棋子（一格一枚），放满为止，放最后一枚者胜。谁有必胜策略？

::: details 习题答案与提示

1. $50 = 5 \times 10$，余 $0$ → **后手必胜**：对方取 $j$ 粒，后手取 $5 - j$ 粒，保持剩余为 5 的倍数。
2. $n = 8$：先手放正中央两格（第 4、5 格）→ 剩两段各 3 格 → 对手在一段放牌后，先手**镜像**放另一段 → 先手必胜。（一般 $1 \times n$：先手取中间制造对称两段。）
3. $100 = 8 \times 12 + 4$ → 先手先报 4 个数（1~4），此后每轮与对方凑 8 → 先手报 100。
4. 每步 $x + y$ 恰增 3 → $x + y \equiv 0 \pmod 3$。目标 $99 + 100 = 199 \equiv 1 \pmod 3$ → **不能到达**。
5. $3 \oplus 4 \oplus 5 = 011 \oplus 100 \oplus 101 = 010 = 2 \ne 0$ → 先手胜。找 $x$ 使 $x \oplus 2 < x$：$x = 3$：$3 \oplus 2 = 1 < 3$ ✓ → 从 3 粒堆取 2 粒剩 1，局面 $1, 4, 5$：$001 \oplus 100 \oplus 101 = 000$ ✓。
6. misère 规则：开局 $3 \oplus 4 \oplus 5 = 2 \ne 0$，先手仍先归零（同第 5 题取法），维持异或零态，直到**只剩一堆多于 1 粒**时，一次把它取到只剩 **1 粒**（把"取最后一粒"的霉运留给对方）。此后对手被迫取那 1 粒而输。
7. $3 \times 3$ 共 9 格（奇数）→ 先手必胜：先手先放**中心格**（对称中心），之后镜像对方——每轮成对放棋，最后一枚必是先手放的（1 + 偶数对）。一般规律：格数奇数 → 先手先占中心再镜像。
8. $9 \times 9 = 81$ 格为奇数 → 放最后一枚的是**先手**（若双方都只能一枚枚放）。策略同第 7 题：先占中心，镜像到底。
:::

## 本节方法小结

- 取子倒推：终局 → 安全余数（$k+1$ 的倍数）→ 初始余 0 则后手胜
- 对称策略三步：**造对称（占中心）→ 镜像 → 可用性传递**；格子数为奇数时先手先占中心
- 不变量必须**先验证后使用**；走法限制往往就是不变量的藏身处
- NIM：异或和为 0 = 必败态；misère 版只在"全 1 结尾"阶段反转策略
- 归纳构造：**分解 + 桥接**（中心 L 掏三角）——既是证明也是算法
