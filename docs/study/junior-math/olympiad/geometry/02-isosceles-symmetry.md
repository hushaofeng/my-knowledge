# 第 2 章 等腰三角形与轴对称

> 等腰三角形是"对折"出来的图形——轴对称是它的灵魂。本章两件大事：**分类讨论**（等腰题的隐形陷阱）与**将军饮马**（对称求最值的祖师爷模型）。

## 知识点精讲

### 1. 等腰三角形性质清单

- 两底角相等（等边对等角）；三线合一（顶角平分线、底边中线、底边高）
- 等角对等边（判定）；两边相等的三角形是等腰三角形
- **等边三角形**：三内角均 $60^\circ$；任一边上的高即中线即角平分线

### 2. $30^\circ$ 直角三角形定理

直角三角形中，$30^\circ$ 角所对的直角边等于斜边的一半。

**逆定理也成立**：直角三角形中若一直角边为斜边一半，则其所对角为 $30^\circ$。

### 3. 分类讨论的两大陷阱（等腰题专属）

| 陷阱 | 原因 | 处理 |
|------|------|------|
| 已知"两边"求第三边 | 谁当腰谁当底要检验 | 用三边关系筛掉非法解 |
| 已知"一个角"求其他角 | 谁当顶角谁当底角 | 按顶角/底角两种情形各算一遍，再用内角和检验 |

### 4. 将军饮马模型（对称求最值）

**问题**：直线 $l$ 同侧两点 $A, B$，在 $l$ 上求点 $P$ 使 $PA + PB$ 最小。

**解法**：作 $A$ 关于 $l$ 的对称点 $A'$，连 $A'B$ 交 $l$ 于 $P$，则 $PA + PB = PA' + PB = A'B$（最小）。

**证明最小性**：对 $l$ 上任意其他点 $P'$，$P'A + P'B = P'A' + P'B \ge A'B$（三角形两边之和），等号当且仅当 $P'$ 落在线段 $A'B$ 上。

**推广**：角内一点 $P$ 到两边的"折线最短"——对两边各作一次对称，两点连线段即答案（见例 4）。

## 经典例题

### 例 1（经典赛题改编）

等腰三角形一腰上的中线把这个三角形的周长分成 12 和 9 两部分，求三边长。

::: details 查看解答

设腰 $AB = AC = 2x$，底 $BC = y$，$AC$ 边上的中线 $BM$（$AM = MC = x$）。

两部分周长：$\triangle ABM$ 部分 $= 3x + BM$，$\triangle BCM$ 部分 $= x + y + BM$。两者之差 $= 2x - y$，总和 $= 21$。

**情形一**：$3x + BM = 12$，$x + y + BM = 9$ → 差 $2x - y = 3$，联立 $2x + y = 21$ → $x = 6, y = 9$。三边 $12, 12, 9$（$12 < 12 + 9$ ✓）合法。

**情形二**：$3x + BM = 9$，$x + y + BM = 12$ → $y - 2x = 3$，$2x + y = 21$ → $x = 4.5, y = 12$。三边 $9, 9, 12$：$9 + 9 = 18 > 12$ ✓ 合法！

等等——检查情形二：腰 $= 2x = 9$，底 $= 12$，$9 + 9 = 18 > 12$，**合法**。

两个解都成立：$\boxed{(12, 12, 9) \text{ 或 } (9, 9, 12)}$。

**方法提炼：** "分成的两部分"谁大谁小未知 → 双情形；每个解都要过三边关系筛子。本题两解都合法，答案不唯一是正常现象。
:::

### 例 2（经典赛题改编）

等腰三角形的一个内角是 $70^\circ$，求另外两个角。

::: details 查看解答

**情形一**：$70^\circ$ 是顶角 → 两底角 $= \dfrac{180^\circ - 70^\circ}{2} = 55^\circ$。答：$55^\circ, 55^\circ$。

**情形二**：$70^\circ$ 是底角 → 顶角 $= 180^\circ - 2 \times 70^\circ = 40^\circ$。答：$70^\circ, 40^\circ$。

答案：$\boxed{55^\circ, 55^\circ \text{ 或 } 70^\circ, 40^\circ}$。（若底角是 $90^\circ$ 以上会有陷阱——如"一个内角是 $100^\circ$"只能当顶角，因为 $100^\circ$ 作底角会超出内角和。）

**方法提炼：** 已知角是"顶角还是底角"两分支；分支结果必须用内角和自检（底角 $\ge 90^\circ$ 直接淘汰）。
:::

### 例 3（经典赛题改编）

$Rt\triangle ABC$ 中，$\angle C = 90^\circ$，$\angle A = 30^\circ$，$BC = 5$。求 $AB$，并证明你的结论。

::: details 查看解答

$AB = 10$（$30^\circ$ 对边是斜边一半）。**证明**：在 $CA$ 上截取 $CD = CB$，连接 $BD$。

$\angle C = 90^\circ$，$CD = CB$ → $\triangle BCD$ 等腰直角 → $\angle CDB = 45^\circ$。

$\angle BDC = \angle A + \angle ABD = 30^\circ + \angle ABD$ → $\angle ABD = 15^\circ$？换更快的标准证法：取 $AB$ 中点……**最短证明（倍长构造等边）**：延长 $BC$ 至 $D$ 使 $CD = BC$，连接 $AD$。$\angle ACD = 90^\circ$ 且 $AC$ 公共 → $\triangle ACD \cong \triangle ACB$（SAS）→ $AD = AB$，$\angle DAC = 30^\circ$。$\angle BAD = 60^\circ$ 且 $AD = AB$ → $\triangle ABD$ **等边** → $BD = AB$，而 $BD = 2BC$ → $AB = 2BC$。$\blacksquare$

**方法提炼：** $30^\circ$ 定理的证明本身就是"倍长构造等边"的范例——见 $30^\circ$、$60^\circ$、$120^\circ$，优先想等边三角形。
:::

### 例 4（经典赛题改编·将军饮马进阶）

$\angle AOB$ 内有一点 $P$，在 $OA$ 上求点 $M$，在 $OB$ 上求点 $N$，使 $\triangle PMN$ 的周长最小。

::: details 查看解答

作 $P$ 关于 $OA$ 的对称点 $P_1$，关于 $OB$ 的对称点 $P_2$，连接 $P_1P_2$。

- $P_1P_2$ 与 $OA$ 的交点取 $M$，与 $OB$ 的交点取 $N$。

此时周长 $= PM + MN + NP = P_1M + MN + NP_2 = P_1P_2$（最小，两点之间线段最短）。

**最小性证明**：任取其他 $M' \in OA$，$N' \in OB$：周长 $= P_1M' + M'N' + N'P_2 \ge P_1P_2$（折线长 ≥ 直线段，逐段用两点之间线段最短）。$\blacksquare$

**方法提炼：** "一折变两折、两折变直线"：每个对称点消灭一段折。注意 $P_1P_2$ 必须**真的穿过角内**（当 $\angle AOB$ 太小或 $P$ 太偏时交点会落在延长线上，此时取顶点 $O$ 的退化情形）。
:::

### 例 5（经典赛题改编）

等腰三角形的一个底角是顶角的 4 倍，求各角。

::: details 查看解答

设顶角 $x$，底角 $4x$：$x + 4x + 4x = 180^\circ \Rightarrow x = 20^\circ$。

三内角为 $\boxed{20^\circ, 80^\circ, 80^\circ}$。

**方法提炼：** "倍数关系 + 等腰"型直接设顶角为 $x$（次数最低），一步列方程。
:::

### 例 6（初中联赛风格·面积法）

求证：等腰三角形底边上任意一点到两腰的距离之和为定值（等于一腰上的高）。

::: details 查看解答

$\triangle ABC$ 中 $AB = AC = a$，$P$ 在 $BC$ 上，$PM \perp AB$ 于 $M$，$PN \perp AC$ 于 $N$。腰上的高为 $h$。

**面积法**：连接 $AP$。

$$S_{\triangle ABC} = S_{\triangle ABP} + S_{\triangle ACP} = \frac12 AB \cdot PM + \frac12 AC \cdot PN = \frac12 a\,(PM + PN)$$

又 $S_{\triangle ABC} = \dfrac12 BC \cdot h_{BC}$，其中 $h_{BC} = \sqrt{a^2 - \left(\frac{BC}{2}\right)^2}$ 恰为腰上的高 $h$（等腰三角形两腰上的高相等：$a \cdot h_{\text{腰}} = BC \cdot h_{BC}$，即 $\frac12 a h_{\text{腰}} = S_{\triangle ABC}$）。

所以 $\dfrac12 a (PM + PN) = \dfrac12 a h$ → $PM + PN = h$（定值）。$\blacksquare$

**方法提炼：** "距离之和为定值"的祖传套路是**面积分割**：大三角形 = 两个小三角形，公共底（腰）上提取公因式。这个技巧在第 3 章（面积问题）将系统化。
:::

## 习题

1. 等腰三角形两边长为 4 和 9，求周长。
2. 等腰三角形一腰上的高与另一腰的夹角为 $30^\circ$，求顶角。
3. 等腰三角形一腰上的中线把周长分成 15 和 6 两部分，求三边长。（注意三边关系筛解）
4. Rt$\triangle$ 中 $30^\circ$ 角所对直角边为 4，求斜边与另一直角边。
5. 平面直角坐标系中 $A(1, 3)$，$B(4, 1)$，点 $P$ 在 $x$ 轴上，求 $PA + PB$ 的最小值。
6. 证明：等边三角形内任意一点到三边距离之和为定值。（提示：面积法三分割）
7. $\triangle ABC$ 中 $AB = AC$，$BD$ 平分 $\angle ABC$ 交 $AC$ 于 $D$，$\angle BDC = 75^\circ$。求 $\angle A$。
8.（压轴）等边 $\triangle ABC$ 边长为 4，$P$ 在 $BC$ 上且 $BP = 1$，$Q$ 在 $AC$ 上。求 $PQ + QA$ 的最小值。

::: details 习题答案与提示

1. 4 作腰：$4 + 4 = 8 < 9$ ✗ 舍；9 作腰：$9, 9, 4$ → 周长 $\boxed{22}$。
2. 高与腰的夹角 $30^\circ$ → 高与底边夹角……设顶角 $A$：一腰上的高与另一腰夹角 $30^\circ$ → 顶角 $= 90^\circ - 30^\circ = 60^\circ$ 或（高在形外时）$90^\circ + 30^\circ = 120^\circ$。两解：$\boxed{60^\circ \text{ 或 } 120^\circ}$（画图验证两种：锐角等腰高在形内、钝角等腰高在形外）。
3. 设腰 $2x$，底 $y$：差 $= |2x - y| = 9$，和 $= 21$。情形一 $2x - y = 9$：$x = 7.5, y = 6$ → 边 $15, 15, 6$ ✓ 合法；情形二 $y - 2x = 9$：$x = 3, y = 15$ → 边 $6, 6, 15$：$6 + 6 = 12 < 15$ ✗ **舍**。答案 $15, 15, 6$。
4. 斜边 $= 2 \times 4 = 8$；另一直角边 $= \sqrt{64 - 16} = \boxed{4\sqrt3}$。
5. $B$ 关于 $x$ 轴的对称点 $B'(4, -1)$，最小值 $= AB' = \sqrt{(4-1)^2 + (-1-3)^2} = \sqrt{9 + 16} = \boxed{5}$。
6. 连接 $P$ 与三顶点，$S_{\triangle ABC} = \frac12 a(d_1 + d_2 + d_3)$（$a$ 为边长），$d_1+d_2+d_3 = \frac{2S}{a} = $ 正三角形的高（定值）。
7. 设 $\angle ABC = x$：$\angle DBC = \frac x2$，$\angle C = x$。$\triangle BDC$：$\frac x2 + x + 75^\circ = 180^\circ$ → $x = 70^\circ$ → $\angle A = 180^\circ - 2 \times 70^\circ = \boxed{40^\circ}$。
8. $A$ 在直线 $AC$ 上 → $QA$ 段"对称不动"：$PQ + QA \ge P$ 到直线 $AC$ 的距离（$Q$ 取垂足时取等）。$PC = 3$，$\angle C = 60^\circ$，距离 $= PC \sin 60^\circ = \dfrac{3\sqrt3}{2}$。最小值 $\boxed{\dfrac{3\sqrt3}{2}}$。
:::

## 本节方法小结

- 等腰题**必分类**：边（腰/底）、角（顶/底），答案过三边关系与内角和**双筛**
- $30^\circ$ 定理的证明 = 倍长造等边；见 $30^\circ/60^\circ/120^\circ$ 优先想等边
- 将军饮马：**对称消灭折线**；角内双动点 = 双对称
- 距离之和定值 → **面积法分割**提取公因式
- 腰上中线分周长 = 方程组 + 双情形 + 三边关系筛
