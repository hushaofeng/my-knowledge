# AI Agent 实战 - 引言知识点

## 核心概念

### Agent 核心公式
- **Agent = LLM + 上下文 + 工具**（三者缺一不可）
- 三种理解层次：
  - 实现层：LLM + 上下文 + 工具
  - 直觉层：大脑（思考决策）+ 眼睛（感知信息）+ 手脚（执行动作）
  - 学术层：Policy（策略）+ Observation Space（观察空间）+ Action Space（动作空间）

### ReAct 循环
- 思考 → 行动 → 观察的迭代过程
- Agent 核心工作模式

### 关键架构概念
| 概念 | 作用 |
|------|------|
| Skill | 动态加载提示词，解决提示词无限膨胀问题 |
| Harness | 解决模型工具调用的不稳定、幻觉、危险操作等问题 |
| Loop Engineering | 通过提议者-审核者机制避免模型过早认为任务完成 |

### 技术术语区分
- **Reasoning → "思考"**：模型展开中间推导的过程
- **Inference → "推理"**：模型的前向计算与部署运行

### 关键技术栈
| 术语 | 定义 |
|------|------|
| KV Cache | 大模型推理中复用历史计算结果的机制 |
| RAG | 检索增强生成：先检索相关文档再让模型生成回答 |
| Agentic RAG | 让 Agent 自主决定何时检索、检索什么 |
| MCP | 工具互操作标准 |
| SFT | 监督微调：用标注数据教模型"照样学样" |
| RL | 强化学习：让模型通过试错和奖励反馈自主提升 |
| VLA | 视觉-语言-动作模型：控制机器人操作 |
| Sim2Real | 从仿真环境迁移到真实环境 |

## 关键观点

### 1. 实践在前，命名在后
- 不是 Anthropic 先发明概念，Agent 才跟着用
- 而是大量 Agent 早就在这么做，才被提炼成架构设计原则
- **启示**：等名词流行才去实践，已经慢了一步

### 2. 好的设计原则穿越模型迭代周期
- 原则描述的不是某个模型的用法，而是智能系统与世界交互的基本模式
- 不因底层模型升级、产品形态创新而改变

### 3. 没有评估，就没有进步
- 评估是科学方法论的地基
- 让 Agent 迭代方向不再依赖直觉，而是基于数据

### 4. SFT 记忆、RL 泛化
- SFT 学会具体模式，RL 提升泛化能力
- 数据与环境比算法更重要

### 5. Coding Agent + 文件系统是通用 Agent 的核心技术基础
- 代码生成不仅用于编程，还可辅助思考、构建知识库、动态创造新工具
- 是 Agent 自举的关键

### 6. Agent 是宇宙演化的新阶段
- Richard Sutton：宇宙演化经历了 尘埃 → 恒星 → 生命 → 智能体 四个阶段
- Agent 能理解自身运作机制，通过生成代码实现自举和自我进化

## 实践要点

### 构建可靠 Agent 的关键方法

1. **动态加载提示词**
   - 解决提示词无限膨胀问题
   - 按需加载 Skills

2. **命令行执行工具**
   - 解决工具列表无限膨胀问题

3. **系统状态栏技术**
   - 让 Agent 感知执行环境、用户时间、工作状态

4. **Harness 机制**
   - 解决模型工具调用的不稳定、幻觉、危险操作、越权操作、指令不遵循等问题

5. **提议者-审核者方法**
   - 解决模型过早认为任务完成的问题

### 获得前瞻性能力的两个关键

1. **拥有对 Agent 能力上限有极高要求的真实业务**
   - 持续获得真实业务反馈
   - 足够复杂的场景才会倒逼架构优化

2. **建立评估机制**
   - 分辨改动是真好还是运气
   - 让迭代方向不依赖直觉

## 扩展思考

### 阅读路径建议
- **Agent 开发者**：顺序阅读第一至八章
- **时间有限**：优先第一章（全局认知）+ 第二章（上下文工程）
- **关注模型训练**：第七章（后训练）+ 第六章（评估）

### 前置知识

**必需**：
- Python 编程基础
- LLM 基本使用经验
- AI 辅助编程工具（Claude Code、Cursor 等）
- 软件工程常识（命令行、Git、JSON、REST API）

**推荐（特定章节）**：
- 机器学习基础（第七章）
- 基础数学：线性代数、概率统计（第 2-3、7 章）
- Web 开发基础（第 4、9 章）
- Transformer 架构理解（第 2、7 章）

### 核心价值定位
- 不是教某个具体算法，而是架构设计原则和工程实践方法论
- 除第七章外，对数学和机器学习要求低
- 强调动手实验（配套代码仓库：https://github.com/bojioli/ai-agent-book）

### 术语约定
- reasoning → 思考（思考链、思考模型、思考 token）
- inference → 推理（推理时、推理成本、推理栈）
- 例外：逻辑推理、多跳推理、空间推理、时序推理保留习惯译法
