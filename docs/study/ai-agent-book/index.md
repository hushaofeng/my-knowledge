## 核心观点速查

### 1. 架构原则

| 原则 | 说明 |
|------|------|
| **实践在前，命名在后** | 架构概念来自实践总结，不是先有名词才有实践 |
| **好的设计原则穿越模型迭代周期** | 原则描述的是智能系统与世界交互的基本模式 |
| **没有评估，就没有进步** | 评估是科学方法论的地基 |

### 2. 训练方法

| 论点 | 说明 |
|------|------|
| **SFT 记忆，RL 泛化** | SFT 学会固定映射，RL 学会可迁移策略 |
| **数据与环境比算法更重要** | 算法够用就行，真正拉开差距的是数据和仿真环境 |
| **先形后神** | SFT 先稳定格式，RL 再塑形策略 |

### 3. 技术基础

| 基础 | 说明 |
|------|------|
| **Coding Agent + 文件系统** | 通用 Agent 的核心技术基础 |
| **上下文决定能力上限** | Agent 能看到什么决定了它能做什么 |
| **Harness 工程决定可靠性** | 模型能力商品化，竞争优势在模型之外的工程实践 |
