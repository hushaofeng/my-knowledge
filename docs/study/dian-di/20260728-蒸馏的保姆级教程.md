## 核心内容

### 什么是"蒸馏"

将书籍、视频、文章或个人技能"蒸馏"为可复用的 Hermes Skill 文档。核心思想源自费曼学习法。

### 蒸馏对象

1. **一本书** - 提取核心知识点、方法论
2. **一项技能** - 步骤、技巧、注意事项

### Skill 的价值

- 可复用的知识资产
- 让 AI 具备特定领域能力
- 持续迭代优化

### 蒸馏流程

1. **信息采集** - 阅读/观看，识别核心内容
2. **结构化提取** - 转化为 Skill 标准格式
3. **Skill 创建** - 使用 `skill_manage` 工具
4. **验证与迭代** - 实际测试并优化
