# 12 · 同桌的你 ⭐⭐⭐（高晓松词曲 / 老狼）

| 项目 | 内容 |
|---|---|
| 难度 | ⭐⭐⭐ 进阶 |
| 拍号/速度 | 4/4 · ♩= 76（校园民谣的"慢"） |
| 口琴 | C 调 |
| 目标 | 弱奏与气声、青春的克制感 |

## 简谱（C 调 · 主歌首段+副歌首句）

```text
明天你是否会想起：
3  3  3  3  2  1  2 | 3 - - - |

昨天你写的日记：
3  3  3  2  1  2 | 1 - - - |

明天你是否还惦记：
3  3  3  3  2  1  2 | 3 - - - |

曾经最爱哭的你：
6, 1  2  1  6, 5, 6, | 1 - - - |

谁娶了多愁善感的你：
6  6  6  5  6  1' 6 | 5 - - - |
```

## 吹奏要点

1. 全曲的魂是"**轻**"：气流减半，像怕吵醒回忆——能吹多轻吹多轻，音断意不断
2. `3 3 3 3 2 1 2` 连续同音+级进，靠**音头的轻重交替**做出民谣的絮语感
3. 副歌 `6 6 6 5 6 1'` 情绪上扬但仍克制：加 20% 气即可，不要"喊"
4. 结尾渐慢渐弱，最后一句可以只吹单音渐消失（收音练法）
