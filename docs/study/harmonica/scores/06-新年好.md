# 06 · 新年好 ⭐⭐

| 项目 | 内容 |
|---|---|
| 难度 | ⭐⭐ 基础 |
| 拍号/速度 | 3/4 · ♩= 100 |
| 口琴 | C 调 |
| 目标 | 三拍子律动（强-弱-弱）、节日气氛 |

## 简谱（C 调）

```text
1  1  1  5 | 3  3  3  1 |
1  3  5  5 | 4' 3' 2  - |
2' 3' 4' - | 6' 5' 3  - |
1' 3' 2' 1'? —— 见下方练习提示
```

> 三拍子曲子第一拍是"强"拍：心里默数 **嘭-恰-恰**。第一段 8 小节练稳后，第二段按同结构（我们唱歌我们跳舞，祝贺大家新年好）自行推算——推算本身也是极好的耳朵训练。

## 吹奏要点

1. 3/4 拍重音永远在每小节第 1 拍：`1 1 1` 的第一个 1 给足气流
2. `4' 3' 2` 高音区下行注意嘴角放松，越紧张音越飘
3. 节日曲子**明快**：断句干脆，别拖泥带水

## 练习任务

- [ ] 数着"嘭恰恰"吹完第一段
- [ ] 春节家庭聚会实吹一次（本曲的终极验收）
