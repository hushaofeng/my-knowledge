# 06 · 新年好 ⭐⭐（完整版 ✅ 传统贺岁曲调）

| 项目 | 内容 |
|---|---|
| 难度 | ⭐⭐ 基础 |
| 拍号/速度 | 3/4 · ♩= 100 |
| 口琴 | C 调 |
| 目标 | 三拍子律动（强-弱-弱）、节日气氛 |

## 完整简谱 + 歌词

```text
| 1  1  1  5 | 3  3  3  1 | 1  3  5  5 | 4  3  2  - |
  新年好呀，新年好呀，祝贺大家新年好

| 2  3  4  - | 4  3  2  - | 1  3  5  5 | 4  3  2  1 |
  我们唱歌，我们跳舞，祝贺大家新年好
```

> 速度建议 ♩=100；三拍子心里默数 **嘭-恰-恰**。尾句落 `1` 收稳。

## 吹奏要点

1. 3/4 拍重音永远在每小节第 1 拍：`1 1 1` 的第一个 1 给足气流
2. `4' 3' 2` 类高音下行嘴角放松，越紧张音越飘
3. 节日曲**明快**：断句干脆，不拖泥带水
