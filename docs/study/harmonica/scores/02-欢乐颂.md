# 02 · 欢乐颂 ⭐

| 项目 | 内容 |
|---|---|
| 难度 | ⭐ 入门 |
| 拍号/速度 | 4/4 · ♩= 100 |
| 口琴 | C 调 |
| 目标 | 音阶连贯不顿挫，乐句间换气 |

## 简谱（C 调 · 主题段）

```text
3  3  4  5 | 5  4  3  2 | 1  1  2  3 | 3  2  2 - |
3  3  4  5 | 5  4  3  2 | 1  1  2  3 | 2  1  1 - |
```

> 中段回到主题结构相同，结尾落在 `2 1 1`——先把这 8 小节练熟，其余自然贯通。

## 吹奏要点

1. `3 3 4 5` 是"同音重复+级进"，注意**两个 3 之间也要重新发力**，别吹成连体婴
2. `5 4 3 2` 下行时气息渐稳，不越吹越轻
3. 乐句换气点固定在 `|` 小节线，养成习惯——以后所有曲子受益

## 练习任务

- [ ] 100bpm 连贯吹完 8 小节无爆音
- [ ] 尝试在心里唱词（"欢乐女神圣洁美丽"）再吹，句法立刻自然
