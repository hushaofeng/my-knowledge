> 版本：1.1.0 | 更新时间：2026-08-14

---

## 五模块框架概览

采用"系统论"和"认知心理学"视角深度萃取，共五个模块：

```
一、核心观点与逻辑骨架（含全书概览+章节速览）
二、认知升维与碰撞
三、专属建议生成（双轨并行）
四、行动计划（三级火箭）
五、跨界联想与质疑
```

---

## 一、📌 核心观点与逻辑骨架

### 1.1 全书概览

**书籍定位**：所属领域、目标读者、写作背景

**全书总结**：用200-300字概括全书核心主题和作者意图

### 1.2 章节速览（按章节顺序）

逐章概述每个章节的核心内容，让读者对全书结构有整体把握：

| 章节 | 核心内容 | 关键观点 |
|------|----------|----------|
| 第1章 | 章节主题概括 | 该章核心论点/结论 |
| 第2章 | ... | ... |
| 第3章 | ... | ... |
| ... | ... | ... |

**注意**：对于章节较多的书籍（如《苏菲的世界》50章），可按逻辑单元合并（如"前中期：古希腊哲学"、"中期：中世纪与文艺复兴"、"后期：近现代哲学"），但每个逻辑单元需列出关键章节的要点。

### 1.3 核心论点

#### 一句话概括
用精炼的语言（不超过300字）概括全书核心。

#### 核心论点
按文本理解罗列核心论点，不限制条数：
1. 论点一：展开2-3句说明
2. 论点二：展开2-3句说明
...（根据实际内容增减）

#### 逻辑模型
描述底层逻辑链条：因为A→导致B→为了解决B提出C→实施C的关键是D

#### 启发思考的5个点
书中引发深度思考的观点或问题，每个点包含：问题引入 + 核心洞察 + 反思指引

模板：
1. **问题引入**？洞察。反思：具体问题
2. ...
3. ...
4. ...
5. ...

## 二、💡 认知升维与碰撞

### 反直觉洞察
书中哪个观点颠覆了常规认知？对技术管理者有哪些思维冲击？

### 系统映射

#### 映射到技术团队管理
将本书核心逻辑映射到技术团队管理，分析可能产生的"涟漪效应"或"意外副作用"。

#### 映射到家庭教育
将本书核心逻辑映射到家庭教育（特别是应对孩子畏难情绪及智力培养），分析可能产生的"涟漪效应"或"意外副作用"。
