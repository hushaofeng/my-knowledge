## 🎯 核心知识点总结

### Hermes Agent 核心特性

1. **多平台集成**
   - 支持飞书、微信、Telegram等
   - 统一的API接口
   - 灵活的消息路由

2. **Skill 系统**
   - 模块化的技能扩展
   - 可复用的技能库
   - 自定义开发框架

3. **配置管理**
   - SOUL.md 配置文件
   - 环境变量管理
   - 多环境支持

4. **MCP 协议**
   - Model Context Protocol
   - 标准化的服务集成
   - 跨平台兼容性

### Harness Engineering 核心理念

1. **约束驱动开发**
   - 预防性设计
   - 错误边界控制
   - 安全执行环境

2. **信息层建设**
   - 项目理解能力
   - 代码分析技术
   - 上下文管理

3. **工程化实践**
   - 可复现的开发流程
   - 标准化的部署方案
   - 完善的监控体系
